# 有源蜂鸣器

> 统一器件迁移说明：本文旧称的“端口”已改为模型的公共方法与 `onDidXxx` 事件；
> 清单为项目根 `package.json`，源码在 `src/`，发布包在聚合 `dist/buzzer/`。本轮只
> 交付仿真内核，不提供新 2D/编辑器视图；历史电气语义与测试基线保持不变。

CT107D 板位号 **SP1**（器件值 `BUZZER`）：正端接 VCC、负端接 ULN2003 的 OUT7（网络
`N_BUZZ`），达林顿拉低时两端构成回路发声。

## 元数据

| 项       | 值                                         |
| -------- | ------------------------------------------ |
| 器件 id  | `buzzer`                                   |
| 文件     | `buzzer/{model.ddl,index.ts,package.json}` |
| 位号前缀 | `SP`                                       |
| 引脚数   | 2                                          |

## 引脚

| 引脚 | 方向/电气    | 说明                                           |
| ---- | ------------ | ---------------------------------------------- |
| `p`  | 被动（正端） | 板上接 VCC                                     |
| `n`  | 被动（负端） | 板上接 ULN2003 OUT7（开集输出，网络 `N_BUZZ`） |

## 行为

两端之间是一段负载电阻，`active` 报告「两端有电压」：

```
active = (P 为高 且 N 非高)
```

- ULN2003 拉低时：P = 5 V、N ≈ 0.02 V（`loadResistance` 默认 100 Ω 与开集输出分压），
  `active = true`。
- 输出释放时：N 被这段负载电阻拉回 VCC，`active = false`。

有源蜂鸣器自带振荡电路，因此只要两端有电压就发声，与固件输出方波还是恒定电平无关。

## 属性与端口

| 属性             | 类型   | 默认 | 说明                             |
| ---------------- | ------ | ---- | -------------------------------- |
| `loadResistance` | number | 100  | 两端的等效串联电阻，决定发声电流 |
| `lowThreshold`   | number | 0.8  | 采样电压低于该值判为逻辑低（V）  |
| `highThreshold`  | number | 2.0  | 采样电压高于该值判为逻辑高（V）  |

| 端口     | 方向 | 类型    | 说明                       |
| -------- | ---- | ------- | -------------------------- |
| `active` | 输出 | boolean | 两端是否构成回路、正在发声 |

`active` 在启动时发布一次，之后只在状态变化时发布。

## 理想化

- 不模拟发声频率、声压、驱动电流上限与机械共振：只区分「有电压」与「无电压」。
- 不建模内部振荡电路、线圈电感与反向电动势。
- 未知电平按低处理（只有 `Logic.high` 当作高）。

## 测试

`test/ct107d/buzzer.test.ts`：负端拉低时 `active` 为真、释放后回到假、负端为高时也不发声；
另有一例验证 `loadResistance` 只改变电流、不改变判定。
