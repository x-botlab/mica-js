# 超声波收发器件

用于 CT107D 官方 `12.0 超声波测距` / `14.0 补充` 固件的独立超声波换能器模型。装配时将
`trig` 接到 MCU 的 `P10`、`echo` 接到 `P11`。本器件不依赖 MCU 内部外设，也不通过话题注入
距离；触发和回波都走真实引脚电平。

## 元数据

| 项       | 值                                       |
| -------- | ---------------------------------------- |
| 器件 id  | `ultrasonic`                             |
| 文件     | `model.ddl` / `index.ts` / `device.json` |
| 位号前缀 | `U`                                      |
| 引脚数   | 4                                        |

## 引脚

| 引脚 | DDL 名 | 方向/电气    | 说明                                             |
| ---- | ------ | ------------ | ------------------------------------------------ |
| TRIG | `trig` | 输入         | 触发脉冲串输入；累计 8 个上升沿确认一次测量      |
| ECHO | `echo` | 输出（推挽） | 空闲为高；触发后经过往返传播时间拉低一个等宽脉冲 |
| VCC  | `vcc`  | 电源         | 5 V 逻辑域                                       |
| GND  | `gnd`  | 电源         | 参考地                                           |

## 行为

1. `trig` 每出现一个上升沿，累计脉冲数加 1，并记录最近边沿时刻。
2. 第 8 个脉冲的下降沿表示完整脉冲串结束，`echo` 此时保持空闲高电平。
3. 经过 `echoUs` 的往返传播时间后 `echo` 拉低，保持同等时间后恢复空闲高。
4. 完整脉冲串结束后若仍有旧的回波定时排队，请求序号会使其失效；新触发重新计算回波
   时刻。
5. 若最后一个上升沿之后 1 ms 没有新边沿，未满 8 个的脉冲串计数清零。

官方固件发送 8 个约 12 µs 的脉冲，随后启动 T1 并等待 `P11` 变低。ECHO 在第 8 个脉冲
下降沿之后等待传播时间再拉低，因此 T1 记录的是往返飞行时间。

## 属性

| 属性               | 默认  | 说明                                                                   |
| ------------------ | ----- | ---------------------------------------------------------------------- |
| `distanceCm`       | 100   | 目标距离（cm），用于计算往返传播时间                                   |
| `echoUs`           | -1    | `>= 0` 时直接作为传播延迟与低脉宽（µs）；`-1` 表示由 `distanceCm` 折算 |
| `outputResistance` | 25 Ω  | ECHO 推挽输出高、低电平时的等效串联电阻                                |
| `lowThreshold`     | 0.8 V | TRIG 低电平上限                                                        |
| `highThreshold`    | 2.0 V | TRIG 高电平下限                                                        |

距离折算公式：

```text
echoUs = round(2 × (distanceCm / 100) / 340 m·s⁻¹ × 1e6)
```

例如 `distanceCm = 100` 时，`echoUs = 5882`，ECHO 在脉冲串后 5.882 ms 拉低并在再过
5.882 ms 恢复高。该时间须落在仿真时间范围内；`distanceCm` 必须为有限非负值，`echoUs` 必须是 `-1` 或非负安全整数。

## 端口

无输入或输出通道；状态完全由 `trig` / `echo` 引脚观测和驱动，适配器没有话题需要发布。

## 实现要点

- 8 脉冲计数与第 8 个下降沿触发在 `reaction trigEdge on trigHigh` 中完成。
- 脉冲间隔重置使用 `lastPulseAt + 1 ms` 的目标时刻和 `await ticks(remaining)`；进程源变化
  只登记 pending，因此循环每次唤醒都从最近边沿重新计算，最终准确收敛到最后一个上升沿后
  1 ms。
- 回波过程使用 `echoDeadline` 与 `echoSequence`：等待期间出现新请求时，旧进程醒来先检查
  序号，不会把新回波提前拉低。
- ECHO 高、低都通过 `outputResistance` 接到 `vcc` / `gnd`，不会悬空；启动初值和每次回波
  结束都回到空闲高。

## 理想化

不模拟 40 kHz 换能器振铃、波束角、温度对声速的影响、最小/最大量程、回波幅度阈值、
传播延迟、驱动强度与电源电流；只保留官方固件判读所需的数字触发/回波时序。

## 测试

`test/ct107d/ultrasonic.test.ts`：空闲为高、前 7 个脉冲不触发、第 8 个下降沿后按距离折算时间
拉低、低脉宽到点后恢复高、`echoUs` 显式覆盖、1 ms 间隔丢弃不完整脉冲串，以及第二次触发
不会沿用旧请求的回波定时。
