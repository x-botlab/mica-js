# 超声波收发器件

> 统一器件迁移说明：本文旧称的“端口”已改为模型的公共方法与 `onDidXxx` 事件；
> 清单为项目根 `package.json`，源码在 `src/`，发布包在聚合 `dist/ultrasonic/`。本轮只
> 交付仿真内核，不提供新 2D/编辑器视图；历史电气语义与测试基线保持不变。

用于 CT107D 官方 `12.0 超声波测距` / `14.0 补充` 固件的独立超声波换能器模型。装配时将
`trig` 接到 MCU 的 `P10`、`echo` 接到 `P11`。本器件不依赖 MCU 内部外设，也不通过话题注入
距离；触发和回波都走真实引脚电平。

## 元数据

| 项       | 值                                        |
| -------- | ----------------------------------------- |
| 器件 id  | `ultrasonic`                              |
| 文件     | `model.ddl` / `index.ts` / `package.json` |
| 位号前缀 | `U`                                       |
| 引脚数   | 4                                         |

## 引脚

| 引脚 | DDL 名 | 方向/电气    | 说明                                                 |
| ---- | ------ | ------------ | ---------------------------------------------------- |
| TRIG | `trig` | 输入         | 每个明确的低→高→低完整脉冲都是候选触发               |
| ECHO | `echo` | 输出（推挽） | 空闲为高；完整脉冲后经过往返传播时间拉低一个等宽脉冲 |
| VCC  | `vcc`  | 电源         | 5 V 逻辑域                                           |
| GND  | `gnd`  | 电源         | 参考地                                               |

## 行为

1. 已知低→高把当前脉冲标记为已武装，同时递增请求序号、撤销尚未完成的旧回波，并让
   `echo` 回到空闲高。
2. 已配对的高→低完成一个完整脉冲；以该下降沿时刻 `F` 建立新请求。没有配对上升沿的
   下降不建立候选，避免初始高电平回落伪造测量。
3. `trig` 进入未知/高阻态时清除武装状态并撤销旧请求，`echo` 回到空闲高；持续高或持续
   低不产生重复候选。
4. 新候选会覆盖旧候选，包括旧回波尚未到达、正处于低电平或即将结束的情况。旧定时任务
   在唤醒时核对请求序号，不能提前拉低或释放新请求的线路。
5. 不要求固定脉冲数量、发射周期、占空比或脉冲串之间的静默窗口。1、5、8、10、20 个
   脉冲以及同一串内的非均匀高/低宽度都按相同规则处理。

官方固件的脉冲串中，后续脉冲的上升沿早于当前候选的回波到达，因此最终只保留最后一个
完整脉冲对应的回波。若两个完整脉冲之间的间隔已经长于传播时间 `D`，前一个回波可能在
后一个脉冲到来前已经发生；这是两个按时间可区分的候选触发，模型没有额外的 1 ms 拼串
计时。

## 回波时序

```text
echoUs = 显式 echoUs >= 0 ? echoUs
         : round(2 × (distanceCm / 100) / 340 m·s⁻¹ × 1e6)
D = echoUs × 1e6 ps
F = 当前候选完整脉冲的下降沿时刻
echoLowAt  = F + D
echoHighAt = F + 2D
```

有效请求下，`echo` 在 `[F, F+D)` 为高、`[F+D, F+2D)` 为低，`F+2D` 后恢复高。低电平
截止与恢复截止分别由独立过程等待；新请求即使令旧的恢复任务继续排队，也不会占用新的
低电平等待。`D = 0` 表示零宽回波，稳定输出保持高，不制造可被当成正宽度测量的伪脉冲。

例如 `distanceCm = 100` 时 `D = 5882 µs`，完整脉冲下降沿后 5.882 ms 拉低并在再过
5.882 ms 恢复高；`distanceCm = 20` 时 `D = 1176 µs`。两个绝对截止必须是安全整数且不超过
模型时间上限，否则在建立请求时报告故障。

## 属性

| 属性               | 默认  | 说明                                                                   |
| ------------------ | ----- | ---------------------------------------------------------------------- |
| `distanceCm`       | 100   | 目标距离（cm），用于计算往返传播时间                                   |
| `echoUs`           | -1    | `>= 0` 时直接作为传播延迟与低脉宽（µs）；`-1` 表示由 `distanceCm` 折算 |
| `outputResistance` | 25 Ω  | ECHO 推挽输出高、低电平时的等效串联电阻                                |
| `lowThreshold`     | 0.8 V | TRIG 低电平上限                                                        |
| `highThreshold`    | 2.0 V | TRIG 高电平下限                                                        |

## 端口

无输入或输出通道；状态完全由 `trig` / `echo` 引脚观测和驱动，适配器没有话题需要发布。

## 实现要点

- `reaction trigEdge on trig.sample.level` 区分 `Logic.low`、`Logic.high` 与
  `Logic.unknown`。只有明确低→高才武装，只有已武装的高→低才完成候选。
- `echoLow` 与 `echoHigh` 分别观察单调递增的 `echoSequence`，各自等待绝对截止。普通
  `process ... on` 不重入，等待期间的新触发只记录 pending；因此不能把低、高两个阶段放进
  同一个长等待，否则旧任务会拖住新请求。两个独立过程配合序号复核，可保证旧等待醒来后
  只退出、不触碰新线路。
- `echoPending` 区分“已武装但尚未完成”与“已建立回波”；上升沿和未知态都会清除它并递增
  序号，使任何旧等待立即失效。
- ECHO 高、低都通过 `outputResistance` 接到 `vcc` / `gnd`，不会悬空；启动初值和每次回波
  结束都回到空闲高。

## 理想化

不模拟 40 kHz 换能器振铃、波束角、温度对声速的影响、最小/最大量程、回波幅度阈值、
传播延迟、驱动强度与电源电流。模型接受某种数字波形不代表该波形已通过真实器件的电气、
声学或时序合规认证；抗噪声与声能阈值不属于本功能模型。

## 测试

`test/ct107d/ultrasonic.test.ts`：1/5/8/10/20 个完整脉冲与非均匀高/低宽度、距离折算与显式
`echoUs`、到达前/低电平中/结束同刻的请求覆盖、间隔长于 `D` 的两个候选、初始高/未配对
下降/未知态、已建立回波在等待高电平或低电平期间进入未知态、持续高/低、`D = 0`、截止
溢出、以及粗/细 `runUntil` 的波形一致性。所有时刻由下降沿和距离公式独立推导。
