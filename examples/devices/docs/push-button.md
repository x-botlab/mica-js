# 轻触按键

CT107D 板位号 **S1（复位）、S4–S19（4 个独立按键 + 3×4 矩阵键盘）**：常开轻触开关，
按下把两端接通。统一器件把真实四脚开关抽象为 `a`/`b` 两端，不是四脚封装。

## 清单

| 项       | 值                                            |
| -------- | --------------------------------------------- |
| 器件 ID  | `example:push-button`                         |
| 目录     | `examples/devices/push-button/`               |
| 清单     | `package.json`                                |
| 源文件   | `src/model.ddl`、`src/index.ts`               |
| 位号前缀 | `S`                                           |
| 引脚数   | 2（`a`、`b`）                                 |

## 引脚

| 引脚 | DDL 名 | 方向/电气 | 说明                  |
| ---- | ------ | --------- | --------------------- |
| A    | `a`    | 无源      | 一端；按下时与 B 相连 |
| B    | `b`    | 无源      | 另一端                |

## 公共接口

| 成员           | 类型                         | 说明                       |
| -------------- | ---------------------------- | -------------------------- |
| `press(value)` | `(boolean) => null`          | `true` 闭合，`false` 松开  |
| `isPressed()`  | `() => boolean`              | 查询模型最近接受的按键状态 |
| `onDidPress` | `Event<ModelEvent<boolean>>` | 按键状态变化               |

## 行为

- 初始 `a.intent <- []`：两端悬空，没有默认的 1 GΩ 假支路。
- `process start` 进入 `loop`，每收到一条 `press` 通道消息：
  - `true`：`a.intent <- [resistor(to: b, resistance: 1)]`；
  - `false`：`a.intent <- []`，移除受控支路，两端重新悬空。
- DDL 同步发送 `pressed` 输出通道；适配器把它转发为 `onDidPress` 并缓存供
  `isPressed()` 查询。
- 本轮只交付仿真内核，不提供新 2D 按帽或编辑器展示适配。

## 理想化

没有抖动与回弹：通道消息被模型消费的那一刻立即闭合/断开，按键消抖由固件负责。没有行程、
接触电阻、机械寿命与多键同时按下的优先顺序。松开是真正移除支路，不是有限大“断开电阻”。
该两端抽象刻意不声明四脚封装；需要四脚物理模型时应单独定义 `a1/a2/b1/b2` 并同步所有
消费者的引脚映射。

## CT107D 接线

独立按键（第一列经 J5 的 2-3 短接直接接地）：

| 位号 | A 端  | B 端      |
| ---- | ----- | --------- |
| `S7` | `GND` | `P30/TXD` |
| `S6` | `GND` | `P31/RXD` |
| `S5` | `GND` | `P32`     |
| `S4` | `GND` | `P33`     |

矩阵键盘（行为 P30–P33，列为 `P42/WR`、`P35`、`P34`）：

| 位号        | A 端（列） | B 端（行）                                     |
| ----------- | ---------- | ---------------------------------------------- |
| `S11`–`S8`  | `P42/WR`   | `P30/TXD`、`P31/RXD`、`P32`、`P33`（自上而下） |
| `S15`–`S12` | `P35`      | 同上                                           |
| `S19`–`S16` | `P34`      | 同上                                           |

复位键 `S1` 接在 `VCC` 与 `RST` 之间。以上接法取自 PDF 的 `P0_EX`/`USER` 页：第一列经 J5
选择接地（独立按键）或 `P44/RD`（作为第 4 列矩阵键）；`RST` 在 MCU 模型里没有对应引脚，
保留为网标。

## 测试

`test/ct107d/push-button.test.ts` 覆盖：

- 清单 `a`/`b` 两脚、公共方法与事件、`flexible` 几何的引脚方向；
- 按下闭合、松开后 1 MΩ 下拉读到低（回归“松开不漏电”）；
- 源也释放时两端悬空且没有模型错误；
- `onDidPress` 历史与 `isPressed()` 查询。

`test/2d/interactions.test.ts` 覆盖动态按帽的监听、查询、输入与释放。
