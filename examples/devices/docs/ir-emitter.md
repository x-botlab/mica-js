# 红外发射数据调制端 `ir-emitter`

> 统一器件迁移说明：公共入口是 `package.json` 的 `model.methods` / `model.events`；
> 载波请求通过 `setCarrier` 提交，逻辑载波通过 `onDidCarrier` 交付。发布包在聚合
> `dist/ir-emitter/`。本器件不修改引擎侧 IR（DeviceIR、编译器 IR 与执行器），也不
> 新增 `ir-link` 两端点器件。

本器件只建模 CT107D 红外发射支路（LD1 的数字侧）的**数据通信逻辑**：`mod` 引脚或
宿主请求表示「38 kHz 载波是否开启」，`carrier` 输出通道把这一位逻辑流交付给测试夹具
或上层业务。它不建模红外 LED、限流电阻、正向电流、发光强度、波长、光路或模拟载波
波形。

## 元数据

| 项       | 值                                                     |
| -------- | ------------------------------------------------------ |
| 器件 id  | `ir-emitter`                                           |
| 文件     | `ir-emitter/{package.json,src/model.ddl,src/index.ts}` |
| 位号前缀 | `U`                                                    |
| 引脚数   | 3                                                      |
| 载波语义 | 布尔「有/无载波」，不是 38 kHz 方波                    |
| 标称供电 | 5 V 逻辑域，实际由 VCC/GND 网络采样判定                |

## 引脚

| 引脚  | 方向/电气 | 说明                                                  |
| ----- | --------- | ----------------------------------------------------- |
| `mod` | 输入      | 数字调制输入，高有效；高表示载波开启，低/悬空表示关闭 |
| `vcc` | 电源      | 电源正端；低于高电平门限时视为未上电                  |
| `gnd` | 地        | 电源地；未确定接地时视为未上电                        |

`mod` 可以直接接 MCU GPIO，也可以接 CT107D 的 **J2 第 5 脚（网络 `N_A2`）**。J2 的
1-3 固定短接把 `P1.0` 接到 U18 整形/驱动链，第 5 脚是红外发射管支路；现有
`jumper-2x3` 模型把第 5 脚保留为未连接的支路引脚。因此：

```
J2.p5 (N_A2)  ──────────────  ir-emitter.mod
ir-emitter.vcc ───────────── 5 V
ir-emitter.gnd ───────────── GND
```

在数字仿真里，`N_A2` 上的调制信号可由 MCU GPIO、测试电平源或宿主直接驱动；本器件
不要求 `jumper-2x3` 新增内部连接，也不改变其 1-3 固定短接、4-6/2-4 接收选择的既有
行为。接收端仍使用现有 `vs1838` / `cx20106a`，其 `carrier` 输入与 `receiving` 输出
API 完全不变。

## 属性

| 属性            | 默认 | 单位 | 说明                 |
| --------------- | ---- | ---- | -------------------- |
| `lowThreshold`  | 0.8  | V    | `mod` 采样判低的上限 |
| `highThreshold` | 2.0  | V    | `mod` 采样判高的下限 |

创建期校验：`0 <= lowThreshold < highThreshold <= 5 V`。

## 方法与事件

| 名称           | 方向 | 类型    | 说明                                       |
| -------------- | ---- | ------- | ------------------------------------------ |
| `setCarrier`   | 方法 | boolean | 提交宿主载波请求；与 `mod` 引脚是逻辑或    |
| `isCarrier`    | 方法 | boolean | 当前逻辑载波状态                           |
| `onDidCarrier` | 事件 | boolean | 逻辑载波变化；启动时发布初值，重复状态不发 |

## 行为

```
powered     = VCC 为逻辑高 且 GND 为逻辑低
modulation  = mod 为逻辑高
carrier     = powered 且 (hostRequest 或 modulation)
```

- `mod` 高或 `setCarrier(true)` 任一成立，`carrier` 为真；两者都撤销才为假。
- 只有 `carrier` 真正变化时才发送 `onDidCarrier`，重复请求不重复发事件。
- VCC 掉电或 GND 失效时 `carrier` 强制为假；恢复供电后，如果 `mod` 仍为高或宿主的
  请求仍保留，则重新为真。
- 启动时先发布一次当前 `carrier` 初值，之后按变化发布。
- `mod` 没有内部上拉/下拉；悬空按未调制处理。需要确定空闲电平时，由外部驱动。

## 与接收端的桥接

本器件没有光电输出引脚；`carrier` 输出通道/事件是逻辑载波流。测试夹具按零延迟把
每次载波变化桥接到现有接收头的 `setCarrier`：

```
ir-emitter.carrier ──(测试夹具)──> vs1838.setCarrier / cx20106a.setCarrier
```

接收头仍按自己的检出/释放去抖工作（VS1838：50 µs 检出、200 µs 释放；CX20106A：
100 µs 检出、150 µs 释放），其 `receiving` 输出保持原 API。桥接不模拟传播延迟、
光强、载波频率匹配或 AGC。

## 测试用示例脉宽帧（不是器件协议）

`test/ir-emitter/link-fixture.ts` 定义了一个仅用于验收的脉宽编码；`ir-emitter`
本身只输出原始载波位流，不实现字节发送方法，也不声称支持 NEC、RC5 或任何厂商协议。

| 段     | 载波开时长 | 载波关时长 | 说明                     |
| ------ | ---------- | ---------- | ------------------------ |
| 前导   | 2000 µs    | 1000 µs    | 解码器用长低脉冲识别帧首 |
| 位 `0` | 400 µs     | 1000 µs    | MSB-first                |
| 位 `1` | 1200 µs    | 1000 µs    | MSB-first                |
| 结尾   | 2000 µs    | 1000 µs    | 解码器用长低脉冲识别帧尾 |

测试夹具按 50 µs 采样接收端 `receiving`，记录低脉冲宽度：`>= 1500 µs` 为长定界，
`>= 900 µs` 为 1，`>= 300 µs` 为 0；随后按 8 位一组恢复字节。阈值留出了接收头
50/100 µs 检出延迟与 150/200 µs 释放延迟造成的脉宽偏移。该编码只存在于测试夹具，
不进入器件公共 API。

## 接法与测试

- `J2.p5 (N_A2)` → `ir-emitter.mod`；`vcc` → 5 V；`gnd` → GND。
- 将 `ir-emitter.carrier` 的当前值/事件桥接到接收头的 `setCarrier`；接收头 OUT 按
  现有文档接外部上拉。
- `test/ir-emitter/device.test.ts`：`mod` 引脚、宿主 `setCarrier`、逻辑或、重复请求
  去重、VCC 掉电/恢复。
- `test/ir-emitter/jumper-link.test.ts`：J2 第 5 脚 `N_A2` 与 `mod` 同网时可直接
  调制载波，且不改变跳线原有接收选择。
- `test/ir-emitter/link.test.ts`：完整「发送多字节数据 → VS1838/CX20106A 接收端恢复
  相同字节」链路；解码只读接收端 `receiving` 的低脉冲宽度，不是发射端布尔量的
  自测透传。
- `test/ir-emitter/artifact.test.ts`：验证 `dist/ir-emitter/` 的模型仍能按 `mod`
  门控 carrier 并在掉电时关闭；清单/入口形状由聚合 artifact 测试覆盖。

## 理想化与非目标

- 不模拟红外 LED、正向电流、发光强度、波长、光功率、光电二极管 I-V、载波模拟波形、
  传播光路、电源电流与保护/续流二极管。
- 不模拟 38 kHz 频率匹配、接收头 AGC、脉冲整形与带宽。
- 不实现任何具体红外协议；帧编码只由测试夹具定义。
- 不新增引擎 IR、`ir-link` 器件或第二套 RPC/通信路径。
