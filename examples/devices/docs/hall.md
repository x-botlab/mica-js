# 三脚开关型霍尔传感器 `hall`

> 统一器件迁移说明：公共入口是 `package.json` 的 `model.methods` / `model.events`，
> 交互通过 `setField` 与 `onDidActive`，不再使用旧式话题字段。发布包在聚合
> `dist/hall/`；本轮只交付仿真内核，不提供新 2D/编辑器视图。

CT107D USER 页的 **U21** 是 3 脚霍尔接口，OUT 接网络 `N_HALL`。本器件把该接口建模为
一个单极性、带迟滞的开关型霍尔传感器，而不是线性霍尔元件。

## 元数据

| 项       | 值                                               |
| -------- | ------------------------------------------------ |
| 器件 id  | `hall`                                           |
| 文件     | `hall/{package.json,src/model.ddl,src/index.ts}` |
| 位号前缀 | `U`                                              |
| 引脚数   | 3                                                |
| 输出类型 | 低有效开漏（需要外部上拉）                       |
| 标称供电 | 5 V 逻辑域，实际由 VCC/GND 网络采样判定          |
| 默认磁场 | `0 mT`                                           |
| 默认阈值 | 吸合点 `Bop = 15 mT`，释放点 `Brp = 10 mT`       |

## 引脚

| 引脚  | 原理图脚 | 方向/电气    | 说明                                                                 |
| ----- | -------- | ------------ | -------------------------------------------------------------------- |
| `vcc` | 1        | 电源         | 电源正端；低于高电平门限时视为未上电                                 |
| `gnd` | 2        | 地           | 电源地；未确定接地时视为未上电                                       |
| `out` | 3        | 输出（开漏） | 吸合时经 `outputResistance` 拉低，释放时移除驱动；高电平来自外部上拉 |

`N_HALL` 接 `out`。仿真板不会自动补上拉电阻；需要真实电气行为时，在 `N_HALL`
与 5 V 之间接一个上拉电阻（测试使用 10 kΩ）。没有上拉时，释放态的 OUT 是悬空的，
探针会读到未知电平，而不是高电平。

## 属性

| 属性               | 默认 | 单位 | 说明                                        |
| ------------------ | ---- | ---- | ------------------------------------------- |
| `field`            | 0    | mT   | 创建时的外加磁场；运行期用 `setField` 更新  |
| `operatePoint`     | 15   | mT   | 吸合点 `Bop`，磁场达到该值时 OUT 拉低       |
| `releasePoint`     | 10   | mT   | 释放点 `Brp`，磁场降到该值及以下时 OUT 释放 |
| `outputResistance` | 25   | Ω    | OUT 开漏拉低时的等效串联电阻                |
| `lowThreshold`     | 0.8  | V    | VCC/GND 采样判低的上限                      |
| `highThreshold`    | 2.0  | V    | VCC 采样判高的下限                          |

创建期校验：`0 <= field <= 1000 mT`、`0 <= releasePoint < operatePoint <= 1000 mT`、
输出电阻在 `0.001..1e9 Ω`、`0 <= lowThreshold < highThreshold <= 5 V`。

## 方法与事件

| 名称          | 方向 | 类型    | 说明                                                                        |
| ------------- | ---- | ------- | --------------------------------------------------------------------------- |
| `setField`    | 方法 | number  | 提交外加磁场（mT）；非有限值或超出 `0..1000` 时抛 `MethodError`，不改变状态 |
| `getField`    | 方法 | number  | 最近一次接受的磁场                                                          |
| `isActive`    | 方法 | boolean | 当前是否吸合（OUT 是否被拉低）                                              |
| `onDidActive` | 事件 | boolean | 吸合状态变化；启动时发布一次初值，重复状态不发                              |

`isActive()` 返回的是模型锁存状态，不是 OUT 引脚电压；没有上拉时 OUT 仍可能悬空，
但 `isActive()` 为真时模型确实在通过 `outputResistance` 下拉。

## 行为

### 迟滞

```
磁场 >= operatePoint        → 吸合（OUT 拉低）
releasePoint < 磁场 < Bop   → 保持上一次状态
磁场 <= releasePoint        → 释放（OUT 移除下拉）
```

磁场变化没有延迟；`setField` 只是提交新的瞬时磁场。重复提交相同值不会重复发
`onDidActive`。

### 供电控制

`vcc` 为逻辑高且 `gnd` 为逻辑低才算上电；否则 `powered` 为假，OUT 立即释放，
`active` 强制为假，并清除内部锁存。重新上电时只按当前磁场与 `operatePoint` 重新
判定：只有磁场仍达到吸合点才再次吸合；处于迟滞区间时保持释放。这个选择让掉电/上电
行为确定，但比真实器件更保守——真实器件掉电后内部状态通常也会丢失。

### 输出电气

吸合时 `out.intent = [resistor(to: gnd, resistance: outputResistance)]`，释放时
`out.intent = []`。因此：

- 外部上拉到 5 V、吸合时 OUT 接近 0 V，探针读低；
- 外部上拉到 5 V、释放时 OUT 接近 5 V，探针读高；
- 无外部上拉、释放时 OUT 悬空，探针读未知（测试夹具的 `probe()` 返回 `2`）。

- `N_HALL` → `hall.out`；`hall.vcc` → 5 V；`hall.gnd` → GND。
- 需要可观察的 OUT 高电平时，在 `N_HALL` 上接 10 kΩ 到 5 V。
- `test/hall/device.test.ts` 覆盖：默认释放、14.9/15 mT 吸合边界、10.1/10 mT 释放

  非法磁场拒绝与恢复，以及创建期非法 `field`/电阻/门限/阈值顺序的 table-driven 用例。
- `test/hall/artifact.test.ts` 验证 `dist/hall/` 的模型仍能以外接上拉开漏吸合和释放；
  清单/入口形状由聚合 artifact 测试覆盖。

## 理想化

- 只做单极性开关量，不提供线性输出、模拟电压或磁场方向。
- 不模拟磁滞温漂、灵敏度分布、输出上升/下降时间、传输延迟、电源电流、负载效应
  和磁通变化率。
- `field` 是瞬时值，单位为 mT；没有磁铁几何、气隙或磁路模型。
- 不模拟 D1–D5 等保护/续流二极管。
