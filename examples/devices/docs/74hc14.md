# 74HC14 六施密特触发反相器

> 统一器件迁移说明：本文旧称的“端口”已改为模型的公共方法与 `onDidXxx` 事件；
> 清单为项目根 `package.json`，源码在 `src/`，发布包在聚合 `dist/74hc14/`。本轮只
> 交付仿真内核，不提供新 2D/编辑器视图；历史电气语义与测试基线保持不变。

CT107D 板位号 **U18**：红外发射载波 / 信号的整形与反相（配 C7 / C8、JS1 / JS2 跳线）。
与普通 74LS04 不同，输入端有施密特迟滞：上升沿使用 `highThreshold`（VT+），下降沿使用
`lowThreshold`（VT-），输入停留在两者之间时保持上一次判定结果。

## 引脚

| 引脚          | 方向/电气    | 说明                                     |
| ------------- | ------------ | ---------------------------------------- |
| `a1` … `a6`   | 输入         | 六个独立反相通道的输入，真实名称 1A … 6A |
| `y1` … `y6`   | 输出（推挽） | Y = !A                                   |
| `vcc` / `gnd` | 电源         | 5 V 逻辑域                               |

## 真值表（每通道）

| 输入条件                        | 输出                     |
| ------------------------------- | ------------------------ |
| 电压高于 `highThreshold`（VT+） | 低                       |
| 电压低于 `lowThreshold`（VT-）  | 高                       |
| 电压在 VT- 与 VT+ 之间、无历史  | 初始按低输入处理，输出高 |
| 电压在 VT- 与 VT+ 之间、有历史  | 保持上一次输入状态       |

没有话题端口。输出以 `outputResistance`（默认 25 Ω）推挽到 `vcc` 或 `gnd`，装配负责把这两根电源引脚接到真实的 5 V / 0 V 网络。

## 属性

| 属性               | 类型   | 默认 | 说明                              |
| ------------------ | ------ | ---- | --------------------------------- |
| `outputResistance` | number | 25   | 推挽输出等效串联电阻（Ω）         |
| `lowThreshold`     | number | 1.5  | 负向阈值 VT-（V），低于该值判为低 |
| `highThreshold`    | number | 2.8  | 正向阈值 VT+（V），高于该值判为高 |

DDL 断言：`outputResistance ∈ [0.001, 1e9]`，`lowThreshold ≥ 0`，
`highThreshold > lowThreshold`。

## 理想化

- 零传播延迟；同刻多输入变化按一次原子重算处理，不产生毛刺。
- 不模拟传播延迟、通道间串扰、输入钳位二极管、输入电流、驱动强度、扇出与电源电流。
- 输入悬空或处于迟滞带内时保持上一次判定结果；上电初值按输入为低处理。
- 不模拟输出上升/下降时间，推挽输出直接按 25 Ω 等效电阻到达电源轨。

## 测试

`test/ct107d/74hc14.test.ts`：

- 元数据：14 根引脚、无端口。
- 六通道在 A=0 / A=1 下逐路反相，并验证单通道切换不影响其它通道。
- 输入停在 1.5–2.8 V 迟滞带内时保持上一次判定：低→2.5 V 仍高，高→2.5 V 仍低。
- 释放输入按低处理，对应输出为高。
