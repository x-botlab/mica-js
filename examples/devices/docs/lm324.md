# CT107D 融合式可调放大器（LM324 模拟前端）

> **包名 `lm324` 只用于 CT107D 器件清单跟踪。** 本器件不是通用 14 脚 LM324，
> 不提供四路独立运放、完整引脚或外部反馈网络求解。它是 CT107D USER 页
> `U26` 模拟前端的 fused 业务模型：内部 `RB4` 电位器控制增益，`IN+`/`IN-`
> 差分电压放大后从 `AIN2` 输出。

## 范围

原图 `U26`、`R34`/`R35`、`R36`–`R39` 与 `RB4` 构成一条可调模拟信号路径：

- `IN+` / `IN-` 来自 `J7`；
- `RB4` 是 10 kΩ 增益调节电位器；
- `R34`、`R35` 是 100 kΩ 输入级反馈电阻；
- `R36`–`R39` 是 100 kΩ 差分级电阻；
- 输出网络名 `AIN2`，接到 `PCF8591` 的 `AIN2`。

本模型只实现这条**板级用途**上的单路可调差分放大：

```text
AIN2 = clamp(gain × (V(IN+) − V(IN−)), GND … VCC)
gain = 1 + 2 × feedbackResistance / RB4
```

从原图抽取的板级要素是：`U26.1` 的 `R36`/`R38` 与 `R37`/`R39` 组成四只
100 kΩ 的差分级（差模增益 1），`U26.2`/`U26.4` 与 `R34`/`R35` 位于输入级，
`RB4` 是两输入级之间的增益电阻。模型按标准可调差分放大关系
`gain = 1 + 2Rf/Rg` 折叠这条路径，不逐引脚复刻 `U26.2`/`U26.4` 的偏置和反馈
细节。

它是行为抽象，不是 `U26` 每个运放引脚的网表复刻。原图中每个运放单元的引脚级
偏置/反馈细节、`U26.3` 未使用单元、`VEE` 负电源和 555 电荷泵都不在本 fused
范围内。这样做的原因与 555 fused 相同：板级用途明确、外部引脚不完整，拆成独立
运放会让消费者误以为可以按通用 LM324 任意接反馈。

不接入 `ct107d` 整板，也不替代任何 `ne555` 或 555 fused 器件。

`RB4` 不暴露为外部三端引脚：它不是板级可接线的独立电位器，而是 fused 内部状态，
因此用 `setWiper` 数据方法调节，而不是增加第二套模拟输入。`IN±`/`AIN2` 则保留
电气引脚，因为它们本来就是 CT107D 的板级网络节点。

## 引脚

| 引脚      | 方向/电气        | 说明                                                  |
| --------- | ---------------- | ----------------------------------------------------- |
| `inMinus` | 输入，被动       | 差分反相输入，真实名称 `IN-`；只读取 `sample.voltage` |
| `inPlus`  | 输入，被动       | 差分同相输入，真实名称 `IN+`；只读取 `sample.voltage` |
| `out`     | 输出，戴维南等效 | 真实名称 `AIN2`；用正电阻网络接到 `vcc`/`gnd`         |
| `vcc`     | 电源             | 输出上轨取该引脚的采样电压                            |
| `gnd`     | 电源             | 输出下轨取该引脚的采样电压；原图 `VEE` 负电源不建模   |

输入引脚没有意图、没有输入偏置电流，也不加载信号源。`vcc`/`gnd` 必须由装配接到
真实固定电位网络；模型不引用板级地，也不生成理想电压源。

## 增益映射与调节语义

`RB4` 是融合在器件内部的电位器，不暴露电气端点。宿主通过公共方法
`setWiper(position)` 调节：

- `position = 0`：滑臂在最小增益端，`RB4` 取 `potResistance`；
- `position = 1`：滑臂在最大增益端，`RB4` 取 `minPotResistance` 端停电阻；
- 中间值按线性阻值插值：
  `RB4(position) = minPotResistance + (potResistance − minPotResistance) × (1 − position)`。

默认参数 `feedbackResistance = 100 kΩ`、`potResistance = 10 kΩ`、
`minPotResistance = 100 Ω`：

| `position` | `RB4`    | 差分增益 `gain` |
| ---------- | -------- | --------------- |
| 0          | 10 kΩ    | 21              |
| 0.25       | 7.525 kΩ | 27.5781         |
| 0.5        | 5.05 kΩ  | 40.6040         |
| 0.75       | 2.575 kΩ | 78.6699         |
| 1          | 100 Ω    | 2001            |

实际 10 kΩ 电位器可以转到 0 Ω；模型用 `minPotResistance` 端停电阻把最大增益
限制为有限值。默认增益范围为 **21…2001**。改变 `feedbackResistance`、
`potResistance` 或 `minPotResistance` 会按同一公式改变范围。

方法语义：

| 方法              | 语义                                                                                              |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| `setWiper(value)` | 提交新的滑臂位置。有限值超出 0…1 时钳位到端点；非有限值抛 `MethodError('lm324/invalid-wiper', …)` |
| `getWiper()`      | 最近一次由模型发布的滑臂位置（0…1）                                                               |
| `getGain()`       | 最近一次由模型发布的差分增益                                                                      |

设置位置后，模型在下一次推进处理输入消息时更新位置/增益，并通过
`onDidSetting` 发布 `{ position, gain }`；输出电压随下一个采样周期刷新。启动时
先发布一次初值；位置未变化时不重复发布。`onDidSetting` 是融合电位器的唯一调节
事件，不另设独立电位器事件。有限越界值由公共方法钳位；绕过方法直接向 DDL
输入通道注入非有限值或越界值是框架错误，会使整板 `faulted`。

## 输出与饱和

输出不是理想电压源。模型把目标电压 `Vtarget = clamp(gain × (V+ − V−), Vgnd,
Vvcc)` 转成戴维南等效：空载电压为 `Vtarget`，串联电阻为 `outputResistance`
（默认 25 Ω，创建期限制在 0.001…100 000 Ω）。实现只用两个正电阻：

- `Vtarget` 落在轨中间时，一条电阻接 `vcc`、一条接 `gnd`，并联值等于
  `outputResistance`；
- `Vtarget` 贴 `vcc` 或 `gnd` 时，只保留对应轨的一条电阻；
- 因此输出具有有限输出阻抗，外部负载会产生可预测的压降，而不是被理想源强行
  钉住。

当所需支路电阻超过电阻合同上限 1 GΩ 时，目标必然落在离某条轨
`outputResistance × (VCC − GND) / 1 GΩ` 以内，此时改用最近轨的单支路近似。
该近似的空载绝对误差不超过：

```text
outputResistance × (VCC − GND) / 1 GΩ
```

默认 25 Ω、5 V 时误差上限约 0.125 µV；允许的上限 100 kΩ、5 V 时约 0.5 mV。
`outputResistance` 的创建期上限设为 100 kΩ，避免 1 GΩ 量级输出电阻把半电源
目标也推入单支路近似区。

例如空载 `Vtarget = 1.05 V`、`outputResistance = 25 Ω` 时，接 25 Ω 到 `gnd`
得到约 0.525 V；接 25 Ω 到 `vcc` 得到约
`(1.05/25 + 5/25) / (1/25 + 1/25) = 3.025 V`。

目标电压被采样到的 `gnd` 与 `vcc` 夹住，所以：

- 5 V 供电时上饱和约 5 V；
- 3.3 V 供电时上饱和约 3.3 V；
- 负差分或低于下轨时下饱和到下轨；
- `vcc`/`gnd` 浮空、输入浮空或 `vcc ≤ gnd` 时，输出释放为高阻（`out.intent = []`），
  不发布伪造电压。

## 时间语义

输入采样与输出刷新按 `updatePeriodUs` 周期进行，默认 **10 µs**。一次输入变化或
增益变化后，`out` 最多延迟一个周期才反映到电气网络；`onDidSetting` 中的增益
在位置消息被处理时立即更新，但输出电压随下一个采样周期刷新。

这是**离散时间行为模型，不是零延迟理想运放**：

- 不建模运放带宽、压摆率、建立时间或连续时间反馈；
- 输出更新只发生在 `ticks` 周期边界，输入采样变化不会在同步 reaction 闭包中
  形成零延迟反馈环；
- 不保证把 `out` 接回 `inPlus`/`inMinus` 构成外部闭环时的稳定性；
- 不用于跟随器、反相闭环或通用运放拓扑验收；
- 改变 `updatePeriodUs` 会同时改变输入采样和输出刷新间隔。

## 理想化

本模型明确省略：

- 四路独立运放、未使用单元 `U26.3` 和完整 14 脚封装；
- 输入偏置电流、输入失调电压/电流、共模抑制比和输入共模范围；
- 运放开环增益、增益带宽积、压摆率、噪声、失真和温度漂移；
- 原图 `VEE` 负电源与 555 电荷泵，因此下轨固定为装配给出的 `gnd`；
- 电阻容差、电位器锥度、接触电阻、机械行程和调节噪声；
- `R36`–`R39` 固定按四只 100 kΩ 匹配处理，差分级增益固定为 1，不单独暴露；
- 电源电流、输出短路保护、负载相关增益和电磁兼容。

因此它适合 CT107D 的直流/慢变模拟量教学链路（例如把外部差分信号放大后送
`PCF8591 AIN2`），不适合精确模拟运放交流特性或任意模拟电路。

## 测试

`test/lm324/device.test.ts` 使用真实 `@mica-js/simulator` 板与测试专用模拟探针：

- 默认 `position = 0` 的增益 21 与 50 mV → 1.05 V；
- 共模抑制、反向差分下饱和；
- 运行期 `setWiper` 改变增益、事件发布、端点钳位、非有限值 `MethodError` 后恢复；
- 运行期外部模拟源经 series/shunt 分压后改变 `IN+`，验证周期采样改变输出；
- 5 V/3.3 V 供电上饱和、0 V 下饱和；
- 25 Ω/100 Ω 输出电阻在 25 Ω/100 Ω 负载下的压降、负载接 `vcc` 的戴维南结果、
  100 kΩ 上限在半电源附近不误贴轨，以及近轨单支路近似的误差上界；
- 输入浮空、`vcc`/`gnd` 浮空、`vcc ≤ gnd` 时输出释放；
- 创建期非法 `updatePeriodUs`、`minPotResistance > potResistance`、`outputResistance`
  等参数拒绝；
- 直接向 DDL 输入通道注入 `NaN`/`±Infinity` 使真实板 `faulted`；
- `updatePeriodUs` 的延迟语义与销毁后的故障状态。

`test/lm324/artifact.test.ts` 装载 `dist/lm324/model.js`，在真实板上复验清单一致性、
初始增益、运行期调增益和有限输出阻抗。
