# MCP4017 7 位 I²C 数字电位器

MCP4017T-104ELT（100 kΩ）单路 7 位 I²C 数字电位器，W–B 两端 rheostat。器件 id 为
`example:mcp4017`，源码在 `mcp4017/`，发布包在 `dist/mcp4017/`。CT117E-M4 页 1 的
U3 使用该型号。

## 与计划文字的差异

实现以 Microchip DS20002147 数据手册和 CT117E_M4 原理图第 1 页为准，计划中有两处
文字不准确：

1. **MCP4017 是 W–B 两端 rheostat，不是 W–VCC/W–B 分压器。** MCP4017 的 A 端在芯片
   内部悬空，W 与 B 之间才是 128 级可变电阻；VDD/VSS 只供数字接口。不存在“W 到 VCC
   的固定/可变电阻支路”，本模型也不添加这条虚构支路。
2. **CT117E 的 R17 右端接 VDD，不是 GND。** 实际网络是 VDD—R17 10 kΩ—W（PB14），
   B 经 J16 接地。因此 W–B 变阻器与 R17 构成真实分压，ADC 可以采到随 code 变化的
   电压。

本仓库的测试按真实图中的 `3.3 V—10 kΩ—W—RWB—B=GND` 接线验证分压。

## 引脚

| 引脚 | DDL 名 | 方向/电气 | 说明                                     |
| ---- | ------ | --------- | ---------------------------------------- |
| VDD  | `vdd`  | 电源      | 数字接口电源；本模型不参与电阻梯求解     |
| VSS  | `vss`  | 地        | 数字接口地                               |
| SCL  | `scl`  | 输入      | I²C 时钟；只采样，不驱动、无时钟拉伸     |
| SDA  | `sda`  | 双向开漏  | 应答与读数据时拉低，其余释放；需外部上拉 |
| W    | `w`    | 电阻端    | 滑臂；与 B 之间为可变电阻                |
| B    | `b`    | 电阻端    | 零刻度端；与 W 之间为可变电阻            |

SDA 没有内部上拉；释放就是空意图，高电平由板级上拉提供。SCL 的 1 MΩ 下拉只用于
给采样一个参考，不是 I²C 总线要求。VDD/VSS 是装配引脚，不产生电阻支路，也不做电源
门控；电阻梯在模型中独立于 VDD/VSS，符合“W/B 是独立无源电阻端”的器件结构，但不
校验数据手册规定的端子电压范围。

## 电阻模型

7 位 wiper 码 `N = 0..127`，端到端电阻 `R_AB`，滑臂电阻 `R_W`：

```text
R_WB = R_AB × N / 127 + R_W
```

默认 `R_AB = 100 kΩ`、`R_W = 100 Ω`，因此：

| code | R_WB      | CT117E 3.3 V / R17 10 kΩ 下的 W 电压 |
| ---- | --------- | ------------------------------------ |
| 0    | 100 Ω     | 0.0327 V                             |
| 63   | 49706.3 Ω | 2.747 V                              |
| 127  | 100100 Ω  | 3.0003 V                             |

code 0 不是理想 0 Ω，仍保留 `R_W`；code 127 为满刻度。W/B 没有极性，模型也不区分
电流方向。CT117E 中 B 接地、W 由 R17 上拉；没有 R17 时 W 只经 `R_WB` 到地，电压为
0。B 浮空时 W–B 不形成到地通路，W 被 R17 拉到 VDD。

## I²C 合同

- 固定 7 位从机地址 `0101111`（0x2F）；写地址字节 0x5E，读地址字节 0x5F。没有地址
  引脚，同一总线只能挂一颗；general call（0x00）不应答。
- START/STOP 由“SCL 高期间 SDA 下降/上升”识别，重复 START 同样处理。SCL 上升沿
  MSB first 采样主机数据；第 8 个下降沿完成字节，第 9 个下降沿推进状态机。
- 写事务：地址匹配后，每个数据字节只取低 7 位，MSB 忽略；数据在应答位期间写入，
  因此一个事务可以连续写多个字节，最后一个字节之后用 STOP 或重复 START 结束。
  地址不匹配时进入忽略阶段，直到下一个 START/STOP，期间不驱动 SDA。
- 读事务：地址匹配后发送 `0xxxxxxx`（当前 wiper）。主机在第 9 个时钟拉低 ACK 时继续
  发送同一 wiper；拉高 NACK 后结束并释放 SDA，随后可 STOP 或重复 START。
- 写后可以直接重复 START 再发读地址，无需先 STOP；读操作没有寄存器指针。
- 上电默认 wiper 为 0x3F（midscale）。模型只实现创建时的 POR 初值，不模拟运行中的
  掉电/欠压复位、RAM 保持阈值或 VDD 上升速率。
- 应答位语义：8 位数据收齐后先暂存，第 9 个时钟应答结束后才更新 `R_WB`；若事务在
  应答前异常中止，数据不落盘。地址 NACK、主机读 NACK 都只释放 SDA，不改变 wiper。

模型的总线状态机与 `at24c02`、`pcf8591` 使用同一套位级 I²C 从机规约（START/STOP、
上升沿采样、第 8/9 个下降沿推进、开漏应答），只是把地址、寄存器语义替换为固定地址
和 7 位 wiper。当前 DDL 没有 include/import，仓库里也不存在独立的共享 I²C DDL 模块，
因此无法把这段状态机抽成单一实现；新增器件必须保持同一套可观察合同。

## 公共接口

| 成员              | 类型           | 说明                                                                                 |
| ----------------- | -------------- | ------------------------------------------------------------------------------------ |
| `getWiper`        | `() => number` | 当前 7 位码（0..127）                                                                |
| `getResistance`   | `() => number` | 当前 `R_WB`，单位 Ω                                                                  |
| `getVoltage`      | `() => number` | 最近一次有效 W 对地电压；无有效采样时抛 `MethodError`，code 为 `voltage/unavailable` |
| `onDidWiper`      | `number`       | wiper 码变化事件                                                                     |
| `onDidResistance` | `number`       | `R_WB` 变化事件                                                                      |
| `onDidVoltage`    | `number`       | W 有效电压变化事件                                                                   |

`voltage` 来自 `w.sample.voltage`；W 网络浮空时不发布电压事件。此前没有有效采样时
`getVoltage` 抛出 `MethodError('voltage/unavailable')`，不会把“无样本”与真实 0 V
混淆。已有有效采样后返回最近一次有效样本；该值是历史样本，不保证等于当前网络状态。

## 实现要点

- 引脚 `w` 的初始意图按 POR code 0x3F 建立 `R_WB`；每次有效写入完整替换该意图。
- 写数据字节时 `pendingWiper` 暂存低 7 位，`pendingWrite` 标记；只有在应答状态的
  第 9 个下降沿才调用 `applyWiper` 并发布 `wiper`/`resistance`。
- `reaction wiperVoltageChanged` 在求解边界后发布真实 W 电压；电压不是宿主注入值。
- 读发送由 `beginTransmit` 装入 `wiperCode & 0x7f`；主机 ACK 时重新发送同一值，NACK
  时进入忽略阶段并释放 SDA。
- START/STOP 都会丢弃未确认的 `pendingWrite`，避免错误的跨事务写入。

## 理想化

- 零传播延迟；无 setup/hold、总线空闲时间、毛刺滤波、超时与多主仲裁。
- 不模拟 wiper 电阻随电压/温度/code 的非线性、端到端电阻 ±20% 容差与温度漂移。
- 不模拟 VDD 门限、电源电流、上电斜率、欠压复位与 RAM 保持；POR 只在创建时给出
  0x3F，运行中不会自动复位。
- 不校验 W/B/SCL/SDA 的绝对电压是否落在 VSS..VDD；这是板级理想化边界。
- 不模拟 A 端，因为 MCP4017 的 A 端在封装内悬空。

## 测试

- `test/mcp4017/device.test.ts`：POR 0x3F、W–B 电阻公式、CT117E 的 3.3 V—10 kΩ—
  W—R_WB—B=GND 分压、无 R17 时恒 0、B 浮空时 W 被拉到 VDD、全浮空的
  `voltage/unavailable`、写 0x80/0xFF 的 7 位截断、连续写、重复写同 code 不发事件、
  写后重复 START 连续读、读完 NACK 后继续时钟释放 SDA、NACK/地址不匹配、数据只在
  应答位写入、SDA 浮空时探针拒绝 unknown、参数边界。

- `test/mcp4017/artifact.test.ts`：装载 `dist/mcp4017/model.js`，用真实仿真板和
  位级 I²C 主机验证上电值、写 0/127 后的电压变化，以及全浮空的
  `voltage/unavailable`。

SDA 使用测试夹具自己的 0.8/2.0 V 阈值探针，ACK 与读数据期间只接受确定的 0/1；
浮空或落在阈值之间立即失败。测试保持 3.3 V CT117E 接线，不通过提高总线电压规避
阈值。所有电压断言都由 `@mica-js/simulator` 的线性电阻网络求解，没有使用宿主假电压。
