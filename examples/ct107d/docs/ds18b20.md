# DS18B20 单总线数字温度传感器

CT107D 板位号 **U5**：1-Wire 数字温度传感器，DQ 接 P14，板上 R11 为 10 kΩ 上拉。

## 元数据

| 项       | 值                                                                               |
| -------- | -------------------------------------------------------------------------------- |
| 器件 id  | `ds18b20`                                                                        |
| 文件     | `model.ddl` / `index.ts` / `device.json`                                         |
| 位号前缀 | `U`                                                                              |
| 引脚数   | 3（TO-92）                                                                       |
| 数据手册 | [ADI（原 Maxim/Dallas）DS18B20](https://www.analog.com/en/products/ds18b20.html) |

## 引脚

| 引脚 | DDL 名 | 方向/电气    | 说明                                                 |
| ---- | ------ | ------------ | ---------------------------------------------------- |
| DQ   | `dq`   | 双向（开漏） | 存在脉冲与读 0 位时拉低，其余释放；需外部 10 kΩ 上拉 |
| VCC  | `vcc`  | 电源         | 外部供电（寄生供电不模拟）                           |
| GND  | `gnd`  | 地           |                                                      |

## 时隙时序

| 事件     | 时序                                                                |
| -------- | ------------------------------------------------------------------- |
| 复位     | 主机拉低 ≥ 480 µs 后释放判复位                                      |
| 存在脉冲 | 从机在释放后 +30 µs 拉低、+120 µs 释放                              |
| 主机写位 | 下降沿开时隙，从机 +15 µs 采样 DQ，LSB first 移位                   |
| 从机读位 | 下降沿开时隙，从机 +15 µs 决定输出：0 位拉低到 +60 µs，1 位保持释放 |

主机在自己拉出的时隙里只拉低 1–2 µs 后释放，再在 +30 µs 附近采样读位。器件把自己
拉低产生的下降沿（存在脉冲、读 0 位）不会被误判成新的时隙：内部用 `sinking` 标记
区分主机边沿与器件自身边沿，只有主机边沿才开时隙。

## 命令

| 字节            | 命令                                | 行为                                                            |
| --------------- | ----------------------------------- | --------------------------------------------------------------- |
| `0x33`          | Read ROM                            | 输出 8 字节 ROM                                                 |
| `0x55`          | Match ROM                           | 随后接收 8 字节 ROM 并逐字节比对，失配后静默到下一次复位        |
| `0xCC`          | Skip ROM                            | 直接进入功能命令阶段                                            |
| `0x44`          | Convert T                           | 固定 750 ms 虚拟时间，完成时采样 `temperature` 写入暂存器并发布 |
| `0xBE`          | Read Scratchpad                     | 输出 9 字节（含动态 CRC8）                                      |
| `0x4E`          | Write Scratchpad                    | 接收 TH、TL、Cfg 三个字节                                       |
| `0xB4` / `0xB8` | Read Power Supply / Copy Scratchpad | 文档化空操作（无寄生供电、无 E²ROM）                            |
| `0xF0` / `0xEC` | Search ROM / Alarm Search           | 未实现，未知 ROM 命令静默                                       |

## 暂存器

| 字节 | 内容     | 上电值                                                 |
| ---- | -------- | ------------------------------------------------------ |
| 0    | 温度 LSB | `0x90`                                                 |
| 1    | 温度 MSB | `0x01`                                                 |
| 2    | TH       | `75`                                                   |
| 3    | TL       | `70`                                                   |
| 4    | 配置     | `0x5F`（12 位）                                        |
| 5–7  | 保留     | `0xFF` / `0x0C` / `0x00`（固定）                       |
| 8    | CRC8     | 前 8 字节的动态 Dallas CRC8（多项式 0x31 / 反向 0x8C） |

温度为 T × 16 的 16 位二进制补码：+25.0 °C → `0x0190`（LSB `0x90`、MSB `0x01`），
−10.5 °C → `0xFF58`（LSB `0x58`、MSB `0xFF`）。取整在转换完成时进行，恰为中点时
远离零。

## 端口与属性

| 端口             | 方向   | 类型   | 说明                                                                           |
| ---------------- | ------ | ------ | ------------------------------------------------------------------------------ |
| `temperature`    | input  | number | 温度注入点（°C，-55..125，默认 25）；每次 Convert T 完成时采样，非有限值被忽略 |
| `temperatureOut` | output | number | 最近一次 Convert T 完成时采样的温度（°C）；转换完成前不发布                    |

| 属性               | 类型   | 默认  | 说明                                      |
| ------------------ | ------ | ----- | ----------------------------------------- |
| `serial`           | number | 47049 | ROM 序列号字段的低 32 位（0..0xFFFFFFFF） |
| `outputResistance` | number | 25    | DQ 拉低时的等效串联电阻                   |
| `lowThreshold`     | number | 0.8   | 低电平上限（V）                           |
| `highThreshold`    | number | 2.0   | 高电平下限（V）                           |

ROM 由工厂期固定：族码 `0x28`、`serial` 的低位在前 4 字节、两个 `0x00`、以及前 7
字节的 Dallas CRC8。序列号默认 47049（0xB7C9）时 ROM 为
`28 C9 B7 00 00 00 00 <CRC>`。

## 实现要点

- 时隙与复位都写成「状态 + 目标时刻 + 序号」的四元组：`reaction dqEdge` 在主机边沿
  记账并递增序号，`process ... on <序号>` 看到序号变化就重启，重新计算
  `await ticks(目标时刻 - now())`，因此重新触发天然取消旧等待，不需要轮询。
- 四个定时过程分工明确：`slotTimer`（+15 µs 的写采样/读驱动）、`presenceTimer`
  （+30 µs 拉低、保持 90 µs）、`releaseTimer`（读 0 位 +45 µs 释放）、`convertTimer`
  （750 ms 转换）。
- 每次总线复位递增 `busGeneration`，各定时器在触发时比对代次，过期请求直接丢弃；
  转换定时器用同一机制实现「复位中止转换」。
- 暂存器与 ROM 内容用 `pure fn` 现算（CRC 动态、保留字节固定），`transmitValue`
  统一取字节，读时隙只关心「当前字节 + 位序」。

## 理想化

- 时隙、复位与转换时序为整微秒调度的理想事件，没有传播延迟、上升沿整形与总线电容。
- 保留字节固定为 `0xFF` / `0x0C` / `0x00`，不可写。
- 无寄生供电（只有外部供电模式），也不模拟供电去耦与电源电流。
- **复位中止进行中的转换**：真实 DS18B20 会继续完成转换，本模型一经复位即丢弃该次
  转换，暂存器保留上一次的值，也不发布 `temperatureOut`。
- 不模拟多器件共总线（单从机）、Alarm 搜索、E²ROM 与配置位的分辨率门控；转换时间
  固定 750 ms（12 位）。
- 未知电平按低处理（只有 `Logic.high` 记作 1），因此外部上拉必须真实存在。

## 测试

`test/ds18b20.test.ts`：存在脉冲的 +30..+120 µs 时序与「100 µs 短脉冲不判复位」、
Skip ROM → Convert T → Read Scratchpad 全事务（25 °C 与 CRC）、转换未完成时读到上电
值且复位中止转换、−10.5 °C 编码为 `0xFF58`、Read ROM 与 Match ROM 命中/失配静默、
Write Scratchpad 写入 TH/TL/Cfg 并可回读。所有读位都由 `dqProbe` 探针确认，10 kΩ
外部上拉到 5 V。

## 旧版对照

旧实现 `dist/public/ds18b20/devices/ds18b20.js` 使用已退役的 `@mica-js/device` IR API
（`ir.event.at` + session 计数器、`ir.bytes`）。本模型保持同一份行为契约（时隙时序、
命令集、温度编码、ROM 与 CRC、复位中止转换），只把事件调度换成 DDL 的「序号 + ticks」
写法，输出端口与属性保持一致。旧 `widgets/ds18b20.*` 画布控件未迁移。
