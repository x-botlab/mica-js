# PCF8591 8 位 A/D + D/A 转换器

CT107D 板位号 **U16**：四通道 8 位 ADC + 单路 8 位 DAC，I²C 接口。板级 A0–A2 接地，
7 位从机地址为 0x48（写字节 0x90、读字节 0x91）。

## 元数据

| 项       | 值                                                                             |
| -------- | ------------------------------------------------------------------------------ |
| 器件 id  | `pcf8591`                                                                      |
| 文件     | `model.ddl` / `index.ts` / `device.json`                                       |
| 位号前缀 | `U`                                                                            |
| 引脚数   | 14（SDA/SCL + A0–A2 + AIN0–AIN3 + AOUT + OSC/EXT + VCC/GND；VREF/AGND 未建模） |
| 数据手册 | [NXP PCF8591](https://www.nxp.com/docs/en/data-sheet/PCF8591.pdf)              |

## 引脚

| 引脚      | DDL 名        | 方向/电气    | 说明                                            |
| --------- | ------------- | ------------ | ----------------------------------------------- |
| SDA       | `sda`         | 双向开漏     | 应答与回读时拉低，其余释放；需外部上拉          |
| SCL       | `scl`         | 输入         | I²C 时钟；从不驱动，无时钟拉伸                  |
| A0–A2     | `a0`–`a2`     | 输入         | 从机地址低位，START 时采样                      |
| AIN0–AIN3 | `vin0`–`vin3` | 被动模拟输入 | 不参与电气解算，值由输入通道 `ain0`–`ain3` 注入 |
| AOUT      | `dac`         | 被动模拟输出 | 不驱动模拟电平，DAC 值只经 `aout` 端口观测      |
| OSC       | `osc`         | 被动         | 内部/外部振荡选择；不模拟                       |
| EXT       | `ext`         | 被动         | 外部时钟；不模拟                                |
| VCC       | `vcc`         | 电源         | 5 V 逻辑域                                      |
| GND       | `gnd`         | 地           | 输出低电平参考                                  |

物理引脚名 AIN0–AIN3 与 AOUT 由 `device.json` 的 `label` 保留；DDL 名改成 `vin0`–`vin3`
与 `dac`，以避开与输入/输出通道 `ain0`–`ain3`、`aout` 的命名冲突。SDA 没有内部上拉，
SCL 的 1 MΩ 下拉只是采样选择；未知电平统一按低处理。

## 行为

- 地址字节为 `1001 A2 A1 A0 R/W#`；A0–A2 在 START 时锁存。地址不匹配时进入忽略阶段，
  直到下一个 START/STOP，期间不驱动 SDA。
- 写事务：第 1 字节是控制字节；bit6 为 DAC 使能、bit2 为通道自动递增、bit1:0 为通道选择，
  bit5/bit4 接受但不模拟。后续每个字节写入 DAC 寄存器，并以 `aout = value / 255` 发布。
- 读事务：返回当前选中通道的 `round(255 × ain[channel])`；自动递增模式下每读出一字节通道
  +1，并在 3 之后回绕到 0。第 9 个上升沿采样主机 ACK/NACK，NACK 结束发送。
- 控制字节写入时更新 `channel` 端口；自动递增推进时同样更新。DAC 寄存器更新不受 bit6
  门控，和旧模型一致。

## 端口

| 端口          | 方向   | 类型   | 说明                                               |
| ------------- | ------ | ------ | -------------------------------------------------- |
| `ain0`–`ain3` | input  | number | 各通道电压比注入点（0..1，默认 0）；超出范围时钳位 |
| `aout`        | output | number | 最近写入的 DAC 值（0..1 = 字节 / 255）             |
| `channel`     | output | number | 当前选中通道（0..3），控制字节或自动递增改变时发布 |

## 实现要点

- 总线状态机与 AT24C02 相同：`derived busCodes` + `reaction busEdge` 识别 START/STOP、
  上升沿采样、8 位结束拉低 ACK、第 9 个下降沿释放；读发送由 `beginTransmit` 立即放置 bit7。
- 四个输入通道各由一个常驻接收过程消费。`process start` 把 `sampling` 置真，四个
  `process captureN on sampling` 同时启动并分别 `await ainN.receive()`，因此四路模拟输入
  互相独立，不要求按固定顺序发送。
- `convertedByte()` 取当前通道的输入值并做 `round(255 × clamped)`；`beginTransmit` 在
  转换之后按控制字节 bit2 推进通道，保证「先转换当前通道，再递增」。
- 输入值在接收时做 `isNaN` 与 0..1 钳位；电压比不参与电气求解。
- `aout` 与 `channel` 在 `process start` 各发布一次初值（0），之后仅在值变化时发布。

## 理想化

零传播与转换延迟；无采样保持；不模拟首次读流水线（真实芯片第一个读字节返回上次转换值，
本模型立即转换）；DAC 使能位 bit6 不门控 `aout` 发布；bit5/bit4、OSC/EXT 与电源电流不
模拟。AOUT 不驱动模拟电平，AIN0–AIN3 不从引脚采样，二者只通过端口观测/注入。DDL 没有
单独的 reset 入口，控制字节、通道与 DAC 寄存器从创建初值 0 开始；注入的模拟输入是环境
状态，不随协议状态复位。

## 测试

`test/pcf8591.test.ts`：DAC 写在 bit6=0 时仍更新 `aout`、通道选择读 `round(255 × 0.5)=128`、
自动递增与 3→0 回绕、控制字节 0xFF 边界与未命中地址 NACK。I²C 由数字源逐位驱动，SDA 用
10 kΩ 外部上拉，ACK 由 `sdaProbe` 探针确认。
