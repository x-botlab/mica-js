# UART 串口探针

独立 UART 探针器件：`rxd` 接 MCU 的 TXD，负责从引脚电平独立复原线上字节；`txd` 接
MCU 的 RXD，负责注入字节。它不依赖 MCU 外设，也不属于固件验收夹具的就地模型，因此可以
进入原理图、画布或 Playground 预览。

## 元数据

| 项       | 值                                       |
| -------- | ---------------------------------------- |
| 器件 id  | `uart-probe`                             |
| 文件     | `model.ddl` / `index.ts` / `device.json` |
| 位号前缀 | `U`                                      |
| 引脚数   | 4                                        |
| 协议     | 8N1，LSB first，空闲高                   |

## 引脚

| 引脚 | DDL 名 | 方向/电气 | 说明                                                   |
| ---- | ------ | --------- | ------------------------------------------------------ |
| RXD  | `rxd`  | 输入      | 接 MCU TXD；逻辑阈值低 0.8 V、高 2.0 V                 |
| TXD  | `txd`  | 输出      | 接 MCU RXD；经 `driveResistance` 主动驱动高/低，空闲高 |
| VCC  | `vcc`  | 电源      | 5 V 逻辑域                                             |
| GND  | `gnd`  | 地        | 参考地                                                 |

## 属性

| 属性              | 默认 | 说明                                                    |
| ----------------- | ---- | ------------------------------------------------------- |
| `baud`            | 9600 | 位时间为 `round(1e12 / baud)` ps；要求位时间至少为 2 ps |
| `driveResistance` | 25 Ω | TXD 拉高到 VCC 或拉低到 GND 时的等效串联电阻            |

## 端口

| 端口   | 方向   | 类型  | 说明                                                       |
| ------ | ------ | ----- | ---------------------------------------------------------- |
| `tx`   | output | bytes | 从 RXD 复原的字节；每完成一个合法 8N1 帧发布一条单字节消息 |
| `rx`   | output | bytes | 经 TXD 注入完成的字节；每个停止位结束后发布一条单字节消息  |
| `send` | input  | bytes | 注入命令；每个元素是一个要发送的字节，单条命令最多 64 字节 |

DDL 与运行时支持 bytes 输入通道，因此这里直接使用 `send: bytes`，没有退化为逐字节
`number`。输入通道允许 8 条命令，溢出策略为 `drop_oldest`；每条命令内部按字节顺序发送。

## 接收行为

接收端持续保持空闲高，按以下顺序处理 `rxd`：

1. `rxd` 由高变低时开启一帧；帧进行中再出现的下降沿不会重开帧。
2. 下降沿后半个位时间采样起始位。若采样为确定高电平，判为假起始并丢弃；未知电平按低。
3. 从起始位中点开始，每隔一个位时间采样一个数据位，共 8 位，LSB first。只有
   `Logic.high` 记作 1，低电平、未知电平与非法采样均按 0。
4. 再过一个位时间采样停止位。停止位必须为确定高电平；低或未知停止位按帧错误静默丢弃，
   不发布 `tx`。
5. 停止位中点后接收状态恢复空闲，可接受紧邻的下一帧起始位。

接收过程不轮询线路：每个下降沿用 `rxSequence` 序号触发一次定时过程，所有采样点都由
`now()` 加整皮秒偏移计算。

## 注入行为

`send` 的消费者独立于发射定时器，持续把新命令复制到私有缓冲。每个字节按下列边界驱动
TXD：

```
t0         起始位低
t0 + 1T    数据位 0（LSB）
...
t0 + 8T    数据位 7（MSB）
t0 + 9T    停止位高
t0 + 10T   停止位结束，发布 rx 字节
```

`T = round(1e12 / baud)`。所有下一步时刻都由 `now()` 或上一绝对边界加上 `T` 算出，
然后用 `await ticks(目标时刻 - now())` 等待。

每次收到新命令都会递增 `injectionSequence`。旧注入在下一个定时唤醒时发现自己的序号
快照已过时并退出；运行时会随后重排同一过程，用最新缓冲从第一个字节重新开始。因此新命令
会替换整条旧命令，而不是把新旧字节串接。若取消发生时 TXD 仍为低，新注入先补一个完整
位时间的高电平，再驱动新的起始位，确保对端能看到新的下降沿。

## 输出适配

`model.ddl` 的 bytes 输出在批次里是只读代理。`index.ts` 对 `tx`、`rx` 的每条消息调用
`slice()`，向同名话题发布真实的 `Uint8Array`；同一批次有多个字节时会逐条发布，而不是只
保留最后一条。

## 理想化

不模拟波特率误差、采样时钟抖动、线路噪声、毛刺滤波、传播延迟、驱动强度与电源电流；
TXD 为理想电阻驱动，RXD 阈值固定为 0.8/2.0 V。接收端在停止位中点恢复空闲，不模拟真实
UART 的停止位剩余时间或接收 FIFO 深度。没有独立的帧错误端口，帧错误只体现为 `tx` 不发布。

## 测试

`test/uart-probe.test.ts` 不依赖 MCU：

- 用数字源逐位驱动 RXD，验证 0xA5 的 LSB-first 复原；
- 只在位中点之后拉高数据位，确认采样发生在中点；
- 未知数据位按低，低/未知停止位产生帧错误且不发布；
- 用探针读取 TXD，逐位验证注入的 start/8 data/stop 边界和 `rx` 发布时刻；
- 中途发送新命令，验证序号取消旧注入并重新开始；
- 用自定义波特率验证 `round(1e12 / baud)` 的位时间换算。
