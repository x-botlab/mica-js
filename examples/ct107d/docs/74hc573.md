# 74HC573 八路透明 D 锁存器

CT107D 板位号 **U6 / U7 / U8 / U9**（四颗共用本模型）：U6 段码/LED、U7 数码管 DS2 段码、
U8 数码管位选、U9 执行器驱动。片选 LE 由 74HC138 译码输出（Y4C–Y7C）与 WR 经 74HC02
组合产生，OE# 接地。

## 元数据

| 项       | 值                                                                       |
| -------- | ------------------------------------------------------------------------ |
| 器件 id  | `74hc573`                                                                |
| 文件     | `model.ddl` / `index.ts` / `device.json`                                 |
| 位号前缀 | `U`                                                                      |
| 引脚数   | 20（8 数据 + LE + OE# + 8 输出 + VCC/GND）                               |

## 引脚

| 引脚  | DDL 名    | 方向/电气           | 说明                       |
| ----- | --------- | ------------------- | -------------------------- |
| D0–D7 | `d0`–`d7` | 输入                | 数据输入（D0 为最低位）    |
| LE    | `le`      | 输入                | 锁存使能，高电平透明       |
| OE#   | `oe`      | 输入                | 输出使能，低有效           |
| Q0–Q7 | `q0`–`q7` | 输出（推挽 / 三态） | 锁存数据输出               |
| VCC   | `vcc`     | 电源                | 5 V 逻辑域，输出高电平参考 |
| GND   | `gnd`     | 地                  | 输出低电平参考             |

## 真值表

| LE  | OE# | Q0..Q7                         |
| --- | --- | ------------------------------ |
| 1   | 0   | 透明：跟随 D0..D7              |
| 0   | 0   | 锁存：保持 LE 下降沿捕获的字节 |
| ×   | 1   | 高阻：八路输出全部释放         |

## 端口

| 端口    | 方向   | 类型   | 说明                                            |
| ------- | ------ | ------ | ----------------------------------------------- |
| `latch` | output | number | 当前锁存字节（0–255），透明变化与 LE 下降沿发布 |

## 实现要点

- `derived followState: FollowState` 汇总「LE 是否为高」与「D 字节」，`process follow on followState`
  在任一变化时重算：LE 为高就把数据写入 `stored` 并刷新八路输出。
- `reaction latchEdge on le.sample.level` 在下降沿捕获当前字节；`reaction enableChanged on oe.sample.level`
  只刷新输出使能。
- 输出用 `resistor(to: vcc|gnd, resistance: outputResistance)`；OE# 为高时写 `[]` 释放。

## 理想化

零传播延迟；LE 下降沿没有 setup/hold 窗口（捕获值就是边沿时刻的电平）；不模拟驱动强度、
扇出、电源电流与输入漏电流；输入没有内部上下拉。悬空输入不按逻辑高处理（数据位读作 0），
低有效的 OE# 悬空时也不算已使能，因此八路输出保持释放。

## 测试

`test/74hc573.test.ts`：透明跟随、下降沿锁存并保持、OE# 三态屏蔽与恢复、悬空输入按低、
`latch` 端口与元数据一致性。输出电平全部由网络上的探针采样，不读器件内部值。
