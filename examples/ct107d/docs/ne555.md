# NE555 定时器（无稳态振荡）

CT107D 板位号 **U15**：接成无稳态多谐振荡器，经 RB3/R8/C14/C16 与 D2/D3 电荷泵为 LCD
生成负压 VEE。本模型是参数化数字相位模型，不还原模拟斜坡。

## 元数据

| 项       | 值                                                      |
| -------- | ------------------------------------------------------- |
| 器件 id  | `ne555`                                                 |
| 文件     | `model.ddl` / `index.ts` / `device.json`                |
| 位号前缀 | `U`                                                     |
| 引脚数   | 8                                                       |
| 数据手册 | [TI NE555](https://www.ti.com/lit/ds/symlink/ne555.pdf) |

## 引脚

| 引脚  | DDL 名  | 方向/电气    | 说明                                         |
| ----- | ------- | ------------ | -------------------------------------------- |
| OUT   | `out`   | 输出（推挽） | 振荡方波输出                                 |
| DISCH | `disch` | 输出（开漏） | 低相拉低、高相释放；空闲高电平由板级上拉提供 |
| RST#  | `rst`   | 输入         | 低电平立即停振，高电平从充电相重启           |
| THRES | `thres` | 被动输入     | 本模型不模拟比较器，电平只由板级接线定义     |
| TRIG  | `trig`  | 被动输入     | 同上                                         |
| CTRL  | `ctrl`  | 被动输入     | 同上                                         |
| VCC   | `vcc`   | 电源         | 5 V 逻辑域，OUT 高电平的参考                 |
| GND   | `gnd`   | 地           | 输出低电平的参考                             |

RST# 没有内部上拉；悬空读到的未知电平按低处理，即上电后保持停振。

## 行为

创建期把 rA/rB/c 属性折叠为两个整数皮秒半周期：

```
tHigh = round(0.693 × (rA + rB) × c × 1e12)   （OUT 高，DISCH 释放，定时电容充电）
tLow  = round(0.693 × rB × c × 1e12)          （OUT 低，DISCH 拉低，电容放电）
```

单个 `process oscillate on running` 在两相之间自续翻转：每相开始时用 `now()` 算出下一个
绝对期限，`await ticks(期限 − now())` 睡到边界；醒来先复查是否已被停振，再翻转相位。
`reaction resetChanged on rst.sample.level` 观察两个边沿：下降沿立刻把 OUT、DISCH 拉低并
停振，上升沿丢弃旧相位、从充电相（高相）重新计时。

## 属性与端口

| 属性               | 默认    | 说明                                      |
| ------------------ | ------- | ----------------------------------------- |
| `rA`               | 10000 Ω | VCC↔DISCH 定时电阻                        |
| `rB`               | 10000 Ω | DISCH↔TRIG 定时电阻                       |
| `c`                | 1e-8 F  | TRIG 对地定时电容                         |
| `outputResistance` | 25 Ω    | OUT 推挽与 DISCH 开漏拉低时的等效串联电阻 |
| `lowThreshold`     | 0.8 V   | RST# 低电平上限                           |
| `highThreshold`    | 2.0 V   | RST# 高电平下限                           |

| 端口        | 方向   | 类型   | 说明                                                |
| ----------- | ------ | ------ | --------------------------------------------------- |
| `frequency` | output | number | `1/(tHigh+tLow)`，单位 Hz，启动时发布一次           |
| `dutyCycle` | output | number | OUT 高相占整个周期的百分比（0–100），启动时发布一次 |

两个端口只取决于参数，相位翻转不会重新发布。

## 实现要点

- 半周期在创建期取整并 `assert` 为安全整数；每次算出的绝对期限也会 `assert` 落在
  0–7.2e15 ps 的仿真时间范围内。
- `process oscillate` 只有一个显式等待，没有轮询；RST# 停振期间旧唤醒即使到点也会先
  复查 `running` 再决定是否驱动引脚。
- 高相时 `disch.intent <- []` 表示释放；停振与低相都写 `resistor(to: gnd, ...)` 拉低。

## 理想化

模拟器件的数字化行为模型：RC 斜坡、1/3·VCC 与 2/3·VCC 比较器阈值、CTRL 输入、DISCH
饱和压降与电源敏感性均不模拟；半周期取整到整皮秒，输出没有传播延迟，也不模拟驱动强度、
温度与电源电流。

## 测试

`test/ne555.test.ts`：5 个周期的每个相位边界卡在公式算出的时刻（±1 ps）、占空比与 DISCH
相位、RST# 立刻停振与从充电相重启（含旧唤醒仍在排队时重启）、悬空 RST# 按低、参数改变后
`frequency`/`dutyCycle` 只发布一次。OUT 与 DISCH 电平都由网络上的探针采样。
