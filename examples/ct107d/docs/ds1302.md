# DS1302 涓流充电实时时钟

CT107D 板位号 **U19**：三线 RTC。X1/X2 接 32.768 kHz 晶振，RST/IO/SCLK 接 MCU 的
P13/P23/P17，VCC1 为备用电池。命令字节按数据手册真实编码实现（bit6 为 RAM 面选、
地址 31 为突发），因此竞赛板驱动常用的 0xBE/0xBF（时钟突发）与 0xFE/0xFF（RAM
突发）可直接使用。

## 元数据

| 项       | 值                                                                             |
| -------- | ------------------------------------------------------------------------------ |
| 器件 id  | `ds1302`                                                                       |
| 文件     | `model.ddl` / `index.ts` / `device.json`                                       |
| 位号前缀 | `U`                                                                            |
| 引脚数   | 8                                                                              |
| 数据手册 | [ADI（原 Maxim/Dallas）DS1302](https://www.analog.com/en/products/ds1302.html) |

## 引脚

| 引脚 | DDL 名 | 方向/电气    | 说明                                                |
| ---- | ------ | ------------ | --------------------------------------------------- |
| RST  | `rst`  | 输入         | 高电平使能三线接口；上升沿复位位计数，下降沿释放 IO |
| SCLK | `sclk` | 输入         | 串行时钟：写数据在上升沿采样、读数据在下降沿驱动    |
| IO   | `io`   | 双向（开漏） | 命令/数据线：读 0 位时拉低，读 1 位时释放给外部上拉 |
| X1   | `x1`   | 被动         | 32.768 kHz 晶振（振荡器物理层不模拟）               |
| X2   | `x2`   | 被动         | 32.768 kHz 晶振（振荡器物理层不模拟）               |
| VCC  | `vcc`  | 电源         | 主电源（数据手册 VCC2）                             |
| VCC1 | `vcc1` | 电源         | 备用电池电源                                        |
| GND  | `gnd`  | 地           |                                                     |

## 命令字节

LSB first 移入，共 8 位：

| 位      | 含义                                  |
| ------- | ------------------------------------- |
| bit7    | 必须为 1；为 0 时整个事务被忽略       |
| bit6    | 面选择：0 = 时钟寄存器、1 = RAM       |
| bit5..1 | 地址：时钟 0..7、RAM 0..30、31 = 突发 |
| bit0    | 1 = 读、0 = 写                        |

常见取值：`0x80`/`0x81` 秒寄存器写/读，`0x8E` WP 寄存器写，`0xBE`/`0xBF` 时钟突发
写/读，`0xC0`/`0xC1` RAM 首字节写/读，`0xFE`/`0xFF` RAM 突发写/读。

## 寄存器

| 地址 | 寄存器 | 编码                                        |
| ---- | ------ | ------------------------------------------- |
| 0    | 秒     | BCD 00..59，bit7 = CH（1 = 停振）           |
| 1    | 分     | BCD 00..59                                  |
| 2    | 时     | BCD 00..23（仅 24 小时制，12 小时制不模拟） |
| 3    | 日     | BCD 01..31                                  |
| 4    | 月     | BCD 01..12                                  |
| 5    | 星期   | BCD 01..07，每次午夜递增                    |
| 6    | 年     | BCD 00..99，对应 2000..2099                 |
| 7    | WP     | bit7 = 写保护                               |

RAM 为 31 字节（`0x00`–`0x1E`）。时钟突发传 8 字节（秒、分、时、日、月、星期、
年、WP），RAM 突发传 31 字节；突发写超出范围时按 8 / 31 回绕。

## 时序行为

- RST 上升沿：位计数归零，接口进入命令阶段，IO 释放。
- RST 下降沿：接口回到空闲，IO 释放。
- 写事务：命令之后每个 SCLK 上升沿采样一位数据，凑满一字节立即生效（单字节或突发
  的一个位置）。
- 读事务：命令第 8 个上升沿之后，每个 SCLK 下降沿把下一位驱动到 IO；0 位拉低，1 位
  释放给外部上拉。单字节读会一直重复同一字节，突发读按字节序号取流内位置。
- 一个字节结束后，突发写的位置继续前进；单字节事务只有在新的 RST 上升沿才重新开始。

## 写保护

- WP = 1 时，时钟寄存器与 RAM 的所有写（单字节与突发）被忽略，读不受影响。
- WP 寄存器自身保持可写：单字节写 `0x8E` 可以随时清保护，竞赛板驱动「清 WP → 写
  时间 → 置 WP」的流程因此可用。
- 时钟突发的第 8 字节同样受 WP 门控：WP = 1 时整段突发（含末尾的 WP 字节）被丢弃。

## 端口

| 端口       | 方向   | 类型    | 说明                                                                       |
| ---------- | ------ | ------- | -------------------------------------------------------------------------- |
| `datetime` | output | bytes   | 固定 19 字节 ASCII `YYYY-MM-DD HH:MM:SS`；每秒走时后与写入时间寄存器后发布 |
| `running`  | output | boolean | CH = 0（时钟在走）时为 `true`，CH = 1 时为 `false`                         |

`datetime` 的每一字节都是直接构造的 ASCII 码：数字位为 `0x30 + 数码`（数码由
`floor(x / 10)` 与 `x % 10` 得到），分隔符为 `-`（0x2D）、空格（0x20）与 `:`（0x3A）。
载荷长度为 19，故通道声明 `bytes(maxLength: 19, capacity: 4)`。CH = 1 停振期间不按时钟
发布，只在秒寄存器被写入时发布一次当前冻结值。

## 实现要点

- `derived bus: Bus` 把 SCLK 与 IO 的同一时刻电平汇成扁平记录，`reaction busEdge`
  只在记录变化时比较 `previous`/`current` 的时钟位：上升沿进接收移位、下降沿进读
  驱动。器件自己拉低 IO 造成的记录变化不会误触发（时钟位没有变化）。
- `reaction resetEdge on rstHigh` 处理 RST 两个方向的边沿。
- 命令字段（面、地址、突发、读写）由 `pure fn` 从 `commandByte` 现算，读流与写落点
  共用同一组判定，避免状态重复。
- 走时由一个 `process start` 里的 `await ticks(1_000_000_000_000)` 循环驱动，进位用
  `pure fn incBcd` 返回 `{ value, carried }`，逐级级联；不轮询、不依赖 `now()` 差值。

## 理想化

- X1/X2 晶振与 32.768 kHz 振荡器不模拟，走时来自内部 1 s 虚拟时间 tick。
- 走时与供电解耦：主电掉电不丢时钟与 RAM（真实芯片由 VCC1 接管，本模型不断电）。
- 涓流充电、12 小时制、时钟精度与温漂不模拟。
- 无效 BCD 原样存储，只在走时进位与 `datetime` 解码时按 BCD 解释。
- 突发写超长字节按 8 / 31 回绕；不模拟传播延迟、驱动强度、电源电流与 IO 电容。
- IO 是开漏端，没有内部上拉；未知电平按低处理（只有 `Logic.high` 记作 1），因此
  外部上拉必须真实存在。

## 测试

`test/ds1302.test.ts`：上电默认时间与 `datetime` 端口、写入 23:59:58 后逐秒跨日跨月、
时钟突发与 RAM 突发整段回读（含 WP 字节与单字节 RAM 访问）、WP 写保护与 WP 寄存器
自写、CH 停振与恢复、闰年二月 29 日。总线由数字源逐位驱动，IO 读回用电平探针，
10 kΩ 外部上拉到 5 V。
