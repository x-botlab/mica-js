# 74LS04 六反相器

CT107D 板位号 **U18**：红外发射载波 / 信号的整形与反相（配 C7 / C8、JS1 / JS2 跳线）。

## 元数据

| 项       | 值                                                            |
| -------- | ------------------------------------------------------------- |
| 器件 id  | `74ls04`                                                      |
| 文件     | `src/devices/74ls04/{model.ddl,index.ts,device.json}`         |
| 位号前缀 | `U`                                                           |
| 引脚数   | 14                                                            |
| 端口     | 无（纯胶水逻辑）                                              |
| 数据手册 | [TI SN74LS04](https://www.ti.com/lit/ds/symlink/sn74ls04.pdf) |

## 引脚

| 引脚          | 方向/电气    | 说明                                     |
| ------------- | ------------ | ---------------------------------------- |
| `a1` … `a6`   | 输入         | 六个独立反相通道的输入，真实名称 1A … 6A |
| `y1` … `y6`   | 输出（推挽） | Y = !A                                   |
| `vcc` / `gnd` | 电源         | 5 V 逻辑域                               |

## 真值表（每通道）

| A   | Y   |
| --- | --- |
| 0   | 1   |
| 1   | 0   |

没有话题端口。输出以 `outputResistance`（默认 25 Ω）推挽到 `vcc` 或 `gnd`，装配负责把这两根电源引脚接到真实的 5 V / 0 V 网络。

## 理想化

- 零传播延迟；同刻多输入变化按一次原子重算处理，不产生毛刺。
- 不模拟 TTL / LS 输入阈值，输入按逻辑域电平判定。
- 不模拟 LS 输入电流。真实 LS 器件的悬空输入会被内部电流拉高，本模型不这样做：悬空电平由板级上 / 下拉决定，未知电平统一按低处理（只有 `Logic.high` 当作 1），因此悬空输入对应的输出为高。
- 不模拟驱动强度、扇出与电源电流。

## 测试

`test/74ls04.test.ts`：

- 元数据：14 根引脚、无端口。
- 六通道在 A=0 / A=1 下逐路反相，并验证单通道切换不影响其它通道。
- 释放输入按低处理，对应输出为高。
