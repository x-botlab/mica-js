# 电磁继电器

CT107D 板位号 **K1**（器件值 `RELAY-SPDT`）：线圈由 ULN2003 的 OUT5（网络 `N_RELAY`）
开集拉低时吸合，两组常开触点把 `m2` 端子接到 GND。

## 元数据

| 项       | 值                                                   |
| -------- | ---------------------------------------------------- |
| 器件 id  | `relay`                                              |
| 文件     | `src/devices/relay/{model.ddl,index.ts,device.json}` |
| 位号前缀 | `K`                                                  |
| 引脚数   | 6                                                    |

## 引脚

引脚编号与原理图一致（左列 4/6/1，右列 5/3/2）：

| 引脚   | 原理图脚 | 电气         | 说明                                        |
| ------ | -------- | ------------ | ------------------------------------------- |
| `coil` | 4        | 线圈驱动端   | 接 ULN2003 OUT5（`N_RELAY`），拉低吸合      |
| `vcc`  | 5        | 线圈正端     | 板上接继电器电源（原理图 `VB`，本包接 VCC） |
| `com`  | 3        | 触点公共端   | 板上接 `m2` 端子                            |
| `no`   | 6        | 常开触点     | 板上接 GND                                  |
| `com2` | 1        | 第二组公共端 | 板上接 GND                                  |
| `no2`  | 2        | 第二组常开   | 板上悬空（NC）                              |

## 行为

```
吸合 = (coil 非高) 且 (vcc 为高)
com  ↔ no  ：吸合时 contactResistance，释放时 openResistance
com2 ↔ no2 ：同上
coil ↔ vcc ：恒为 coilResistance
```

吸合判定看线圈两端：开集输出把 `coil` 拉到约 0.29 V（400 Ω 线圈与 25 Ω 开集输出分压），
`vcc` 保持 5 V，因此吸合；驱动端释放后线圈把 `coil` 拉回 VCC，两端无电压，释放。

## 属性与端口

| 属性                | 类型   | 默认 | 说明                                    |
| ------------------- | ------ | ---- | --------------------------------------- |
| `coilResistance`    | number | 400  | 线圈等效直流电阻（Ω），决定吸合电流     |
| `contactResistance` | number | 0.05 | 触点闭合时的导通电阻（Ω）               |
| `openResistance`    | number | 1e9  | 触点断开时的绝缘电阻（Ω），避免孤立支路 |
| `lowThreshold`      | number | 0.8  | 线圈驱动端的低电平上限（V）             |
| `highThreshold`     | number | 2.0  | 线圈正端的高电平下限（V）               |

| 端口        | 方向 | 类型    | 说明                 |
| ----------- | ---- | ------- | -------------------- |
| `energized` | 输出 | boolean | 是否吸合（触点闭合） |

## 理想化

- 没有吸合/释放延时与触点弹跳：线圈电平一变，触点立即切换。
- 不模拟线圈电感与反激电压；板上并联的续流二极管 D1 与线圈侧 L10/R24 网络不建模。
- 不模拟接触电阻温漂、触点寿命与触点抖动。
- 第二组触点（`com2`–`no2`）与第一组同步动作，即使板上它只接了 GND 与悬空脚。
