# AT24C02 2Kb I²C 串行 EEPROM

CT107D 板位号 **U4**：256 字节两线 EEPROM。板级 A0–A2 接地，7 位从机地址为 0x50
（写字节 0xA0、读字节 0xA1）；SDA/SCL 挂 P21/P20，WP 由跳线决定。

## 元数据

| 项       | 值                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------ |
| 器件 id  | `at24c02`                                                                                        |
| 文件     | `model.ddl` / `index.ts` / `device.json`                                                         |
| 位号前缀 | `U`                                                                                              |
| 引脚数   | 8（SDA + SCL + A0–A2 + WP + VCC/GND）                                                            |
| 数据手册 | [Microchip AT24C01A/02（doc0180）](https://ww1.microchip.com/downloads/en/DeviceDoc/doc0180.pdf) |

## 引脚

| 引脚  | DDL 名    | 方向/电气 | 说明                                   |
| ----- | --------- | --------- | -------------------------------------- |
| SDA   | `sda`     | 双向开漏  | 应答与回读时拉低，其余释放；需外部上拉 |
| SCL   | `scl`     | 输入      | I²C 时钟；从不驱动，无时钟拉伸         |
| A0–A2 | `a0`–`a2` | 输入      | 从机地址低位，START 时采样             |
| WP    | `wp`      | 输入      | 写保护，高电平丢弃数据字节但仍应答     |
| VCC   | `vcc`     | 电源      | 5 V 逻辑域                             |
| GND   | `gnd`     | 地        | 输出低电平参考                         |

SDA 没有内部上拉：释放就是 `[]`，高电平必须由板级外部上拉提供。SCL 的 1 MΩ 下拉只是
采样选择，不是 I²C 总线要求；未知电平统一按低处理（只有 `Logic.high` 记作 1）。

## 行为

- 地址字节为 `1010 A2 A1 A0 R/W#`；A0–A2 在 START 时锁存。地址不匹配时进入忽略阶段，
  直到下一个 START/STOP，期间不驱动 SDA。
- START/STOP（含重复 START）由「SCL 高期间 SDA 下降/上升」识别；SCL 低期间的数据变化
  （包括本器件自身产生的 ACK 与发送位）不参与判定。
- SCL 上升沿按 MSB first 采样主机数据位；第 8 个下降沿完成字节并拉低 SDA 应答，第 9 个
  下降沿释放。主机在读事务的第 9 个上升沿给出 ACK/NACK：拉低继续发送下一字节，高电平
  结束发送。
- 写事务：第 1 字节为字地址（模 256 回绕），后续数据字节顺序写入；写指针在 8 字节页内
  回绕（0x07 之后回到 0x00）。WP 为高时数据字节被丢弃、指针不前进，但仍然应答。
- 读事务：读地址的 R/W# 为 1 时从当前指针开始发送；指针在整个 256 字节阵列内回绕，
  不按页回绕。随机读由「dummy write 设字地址 + 重复 START + 读地址」完成。
- 每个数据字节在它的应答时钟落盘，没有 STOP + tWC 等待。

## 端口

| 端口   | 方向   | 类型  | 说明                                                          |
| ------ | ------ | ----- | ------------------------------------------------------------- |
| `dump` | output | bytes | 全部 256 字节映像。上电发布一次，之后仅在内容真正改变时发布。 |

## 实现要点

- `derived busCodes` 把 SCL/SDA 采样编码为「高 1 / 低 0 / 未知 2」，`reaction busEdge`
  在一次发布边界内同时比较前后编码，因此 START/STOP 的判定条件是 SCL 在前后两个采样中
  都为高。
- 接收阶段在上升沿移位，第 8 个下降沿调用 `finishReceivedByte`；应答状态在第 9 个下降沿
  释放 SDA，再按 `nextPhase` 进入写数据、读发送或忽略。
- 读发送由 `beginTransmit` 装载 `storage[pointer]` 并立即放置 bit7；后续每个下降沿放置
  下一位，8 位发完后释放 SDA 等待主机 ACK/NACK。
- `dump` 用 `copyBytes(storage, 0, 256)` 生成不可变快照；只有新旧字节不同才发送，重复写入
  相同值不会产生端口消息。
- 存储是 256 字节 `memory`，在实例生命周期内保持；DDL 没有单独的 reset 入口，协议状态
  从 `idle` 开始，存储不会因复位动作被清空。

## 理想化

零传播延迟；无 setup/hold 与总线空闲时间窗；无多主仲裁；无写周期延迟（每个字节在应答时
落盘，而非 STOP + tWC 之后）；无电源电流、驱动强度与输入漏电流建模。SDA 的未知电平按低
处理，不把悬空当作逻辑高。

## 测试

`test/at24c02.test.ts`：位级写 + 随机读、当前地址连续读与 0xFF→0x00 回绕、8 字节页写
回绕、WP 高时丢弃但仍应答、`dump` 上电与变化发布。SDA 用 10 kΩ 外部上拉，ACK 与读数据
位由网络上的 `sdaProbe` 探针采样。
