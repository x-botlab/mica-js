# 2×3 跳线排针

CT107D 板位号 **J2**（红外收发选择）：1-3 固定短接把 `P1.0` 接到 U18 整形/驱动链，
接收端公共脚 4 由 `vs1838` 属性在 4-6（VS1838）与 2-4（CX20106A）之间选择。

## 元数据

| 项       | 值                                                        |
| -------- | --------------------------------------------------------- |
| 器件 id  | `jumper-2x3`                                              |
| 文件     | `src/devices/jumper-2x3/{model.ddl,index.ts,device.json}` |
| 位号前缀 | `J`                                                       |
| 引脚数   | 6                                                         |

## 引脚

引脚编号与原理图一致（左列 1/3/5，右列 2/4/6）：

| 引脚 | 原理图脚 | 网络   | 说明                           |
| ---- | -------- | ------ | ------------------------------ |
| `p1` | 1        | `N_A1` | 发送通路，固定短接到 3         |
| `p2` | 2        | `N_B1` | CX20106A 输出                  |
| `p3` | 3        | `P10`  | MCU `P1.0`                     |
| `p4` | 4        | `P11`  | MCU `P1.1`，接收端公共脚       |
| `p5` | 5        | `N_A2` | 红外发射管支路（不插帽时悬空） |
| `p6` | 6        | `N_B2` | VS1838 输出                    |

## 行为

```
p1 ↔ p3 ：恒定短接（resistance，默认 0.05 Ω）
p4 ↔ p6 ：vs1838 为 true 时短接
p4 ↔ p2 ：vs1838 为 false 时短接
```

也就是说：`P1.0` 始终经 U18 驱动红外发射链；`P1.1` 在两种接收头之间二选一。

## 属性

| 属性         | 类型    | 默认 | 说明                                          |
| ------------ | ------- | ---- | --------------------------------------------- |
| `vs1838`     | boolean | true | true = 4-6（VS1838），false = 2-4（CX20106A） |
| `resistance` | number  | 0.05 | 插帽时的导通电阻（Ω）                         |

## 理想化

- 没有插拔过程与接触电阻漂移，也不检查同一列插多个跳线帽的冲突。
- 未选中的接收头引脚保持悬空（对应板上拔掉的那一列）。

## 测试

`test/jumper-2x3.test.ts`：1-3 恒导通；默认 `vs1838` 下 4-6 导通、2-4 断开；
`vs1838: false` 时相反。
