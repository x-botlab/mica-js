# 轻触按键

CT107D 板位号 **S1（复位）、S4–S19（4 个独立按键 + 3×4 矩阵键盘）**：常开轻触开关，
按下把两端接通。`press` 端口是唯一输入，端口给 `true` 时闭合。

## 元数据

| 项       | 值                                       |
| -------- | ---------------------------------------- |
| 器件 id  | `push-button`                            |
| 文件     | `model.ddl` / `index.ts` / `device.json` |
| 位号前缀 | `S`                                      |
| 引脚数   | 2（A、B）                                |

## 引脚

| 引脚 | DDL 名 | 方向/电气 | 说明                  |
| ---- | ------ | --------- | --------------------- |
| A    | `a`    | 无源      | 一端；按下时与 B 相连 |
| B    | `b`    | 无源      | 另一端                |

## 端口

| 端口    | 方向  | 类型    | 说明                                     |
| ------- | ----- | ------- | ---------------------------------------- |
| `press` | input | boolean | `true` 闭合（1 Ω），`false` 断开（1 GΩ） |

## 行为

- `pin a = [resistor(to: b, resistance: 1_000_000_000)]`：默认断开。
- `process start` 进入 `loop`，每收到一条 `press` 就把 `a` 的意图换成
  `resistor(to: b, resistance: pressed ? 1 : 1_000_000_000)`。
- 适配器把话题 `press` 的布尔负载转成通道消息，重复值被丢弃。

## 理想化

没有抖动与回弹：端口投递的那一刻立即闭合/断开，按键消抖由固件负责。没有行程、接触电阻、
机械寿命与多键同时按下的优先顺序。断开的 1 GΩ 不是真正开路，只是为了两端仍被网络引用，
避免电气求解出现孤立支路。

## CT107D 接线

独立按键（第一列经 J5 的 2-3 短接直接接地）：

| 位号 | A 端  | B 端      |
| ---- | ----- | --------- |
| `S7` | `GND` | `P30/TXD` |
| `S6` | `GND` | `P31/RXD` |
| `S5` | `GND` | `P32`     |
| `S4` | `GND` | `P33`     |

矩阵键盘（行为 P30–P33，列为 `P42/WR`、`P35`、`P34`）：

| 位号        | A 端（列） | B 端（行）                                     |
| ----------- | ---------- | ---------------------------------------------- |
| `S11`–`S8`  | `P42/WR`   | `P30/TXD`、`P31/RXD`、`P32`、`P33`（自上而下） |
| `S15`–`S12` | `P35`      | 同上                                           |
| `S19`–`S16` | `P34`      | 同上                                           |

复位键 `S1` 接在 `VCC` 与 `RST` 之间。以上接法取自 PDF 的 `P0_EX`/`USER` 页：第一列经 J5
选择接地（独立按键）或 `P44/RD`（作为第 4 列矩阵键）；`RST` 在 MCU 模型里没有对应引脚，
保留为网标。

## 测试

闭合行为由 `verify-canvas.mjs` 逐键验证：17 个键各按一次，检查矩阵行/列与 `RST` 的电平变化。
