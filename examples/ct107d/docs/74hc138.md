# 74HC138 3-8 译码器

CT107D 板位号 **U24**：P25 / P26 / P27 经 A / B / C 译码产生 Y4C–Y7C 等锁存器片选；E1# / E2# / E3 为使能输入。

## 元数据

| 项       | 值                                                              |
| -------- | --------------------------------------------------------------- |
| 器件 id  | `74hc138`                                                       |
| 文件     | `src/devices/74hc138/{model.ddl,index.ts,device.json}`          |
| 位号前缀 | `U`                                                             |
| 引脚数   | 16                                                              |
| 数据手册 | [TI SN74HC138](https://www.ti.com/lit/ds/symlink/sn74hc138.pdf) |

## 引脚

| 引脚               | 方向/电气    | 说明                                   |
| ------------------ | ------------ | -------------------------------------- |
| `a` / `b` / `c`    | 输入         | 选择位（A 为低位），真实名称 A / B / C |
| `e1` / `e2` / `e3` | 输入         | 使能：E1#=0、E2#=0、E3=1 时译码有效    |
| `y0` … `y7`        | 输出（推挽） | 低有效译码输出，真实名称 Y0#–Y7#       |
| `vcc` / `gnd`      | 电源         | 5 V 逻辑域                             |

## 真值表

| E1#          | E2# | E3  | 输出                      |
| ------------ | --- | --- | ------------------------- |
| 0            | 0   | 1   | Yn# 低（n = CBA），其余高 |
| 其他任意组合 |     |     | 八路输出全部高            |

## 端口

| 端口      | 方向 | 类型    | 说明                                                                        |
| --------- | ---- | ------- | --------------------------------------------------------------------------- |
| `select`  | 输出 | number  | 当前选中的 0–7；禁用时为 -1                                                 |
| `enabled` | 输出 | boolean | 使能条件是否满足                                                            |
| `code`    | 输出 | bytes   | 两个 ASCII 字节：选中的输出写作 `"Y0"`–`"Y7"`，禁用写作 `"--"`（0x2D 0x2D） |

`code` 用字节而非字符串，是为了满足通道负载类型约束；第一个字节恒为 `'Y'`（0x59）或 `'-'`（0x2D），第二个字节为 `'0'`–`'7'` 或 `'-'`。

输出以 `outputResistance`（默认 25 Ω）推挽到 `vcc` 或 `gnd`，装配负责把这两根电源引脚接到真实的 5 V / 0 V 网络。端口只在译码结果变化时发布，初始化时先发布一次当前值。

## 理想化

- 零传播延迟；同刻多输入变化按一次原子重算处理，不产生毛刺。
- 未知电平统一按低处理（只有 `Logic.high` 当作 1）：悬空的 `e1` / `e2` 视为低（满足低有效使能），悬空的 `e3` 视为低（禁用），悬空的 `a` / `b` / `c` 视为 0。
- 不模拟输入阈值回差、驱动强度与电源电流。

## 测试

`test/74hc138.test.ts`：

- 元数据：16 根引脚，`select` / `enabled` / `code` 的类型。
- 使能状态下 8 种选择组合：只有选中的一路为低，`select` / `enabled` / `code` 同步更新。
- E1#=1、E2#=1、E3=0 三条禁用路径：八路全高，端口回到 -1 / false / `"--"`。
- 释放的使能输入按低处理：E3 悬空视为禁用。
