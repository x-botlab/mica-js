# ULN2003 七路达林顿驱动阵列

CT107D 板位号 **U10**：OUT1–OUT7 板级接 STEPA–STEPD（步进电机）、N_RELAY（继电器）、N_MOTOR（直流电机）、N_BUZZ（蜂鸣器），以灌电流方式驱动执行器。

## 元数据

| 项       | 值                                                            |
| -------- | ------------------------------------------------------------- |
| 器件 id  | `uln2003`                                                     |
| 文件     | `src/devices/uln2003/{model.ddl,index.ts,device.json}`        |
| 位号前缀 | `U`                                                           |
| 引脚数   | 16（无 VCC——真实芯片只灌不拉）                                |
| 数据手册 | [TI ULN2003A](https://www.ti.com/lit/ds/symlink/uln2003a.pdf) |

## 引脚

| 引脚            | 方向/电气        | 说明                                             |
| --------------- | ---------------- | ------------------------------------------------ |
| `in1` … `in7`   | 输入             | 各通道控制输入（高 = 导通），真实名称 IN1–IN7    |
| `out1` … `out7` | 输出（开集电极） | 导通时拉低到地，释放时为高阻，真实名称 OUT1–OUT7 |
| `com`           | 被动             | 感性负载续流公共端（接负载电源），仅声明不驱动   |
| `gnd`           | 地               |                                                  |

## 真值表（每通道，开集电极）

| IN  | OUT                            |
| --- | ------------------------------ |
| 1   | 通过 25 Ω 拉低（灌电流到 GND） |
| 0   | 释放（高阻，电平由负载侧决定） |

输出不带上拉：释放状态要用外部上拉（测试里用 10 kΩ 到 5 V）才能读到高电平。

## 端口

| 端口       | 方向 | 类型   | 说明                                                             |
| ---------- | ---- | ------ | ---------------------------------------------------------------- |
| `mask`     | 输出 | number | 七路输入状态的位掩码（0–127），bit0..bit6 对应 IN1..IN7          |
| `channels` | 输出 | bytes  | 七个 ASCII 字节，IN1..IN7 依次为 `'1'` / `'0'`，例如 `"1010000"` |

端口只在掩码变化时发布，初始化时先发布一次当前值。

## 理想化

- 零传播延迟；同刻多输入变化按一次原子重算处理，不产生毛刺。
- 导通压降按 0 V 计（真实达林顿约 0.9 V）。
- 不模拟达林顿输入电流（真实约 1 mA / 通道）、输出电流限幅与热效应。
- 续流二极管不模拟：`com` 只是声明出来的被动引脚，不驱动、不钳位。
- 未知电平统一按低处理（只有 `Logic.high` 当作 1），因此悬空输入对应的通道为释放状态。

## 测试

`test/uln2003.test.ts`：

- 元数据：16 根引脚、没有 VCC、`mask` / `channels` 的类型。
- 逐通道 IN=1 时 OUT 读低、IN=0 时 10 kΩ 上拉后读高，同时检查 `mask` 与 `channels`。
- 混合模式同时驱动多路，引脚电平与两个端口一致。
- `com` 无驱动：只有被动引脚的网络上探针读到未知电平。
