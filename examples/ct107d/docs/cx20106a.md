# CX20106A 红外接收前置放大/整形

CT107D 板位号 **U11**：红外接收前置放大与整形，中心频率 f0 由外接电阻 R6 设定（板上约
38 kHz）。本模型是解调去抖行为模型，比一体化接收头 VS1838 更「裸」一级。

## 行为

`carrier` 输入通道驱动的去抖状态机（时延与一体化头不同）：

- `carrier=true`：100 µs 检出定时器到点后把 OUT 拉低；
- `carrier=false`：150 µs 释放定时器到点后释放 OUT；
- 输入翻转先取消相反相位的挂起定时，重复电平不重臂。

检出与释放各自有一个定时过程（`process detectTimer on detectArmed` /
`process releaseTimer on releaseArmed`），期限用 `now() + 时延` 算成绝对时刻，睡到期限后
复查 `armed` 与当前解调状态。两个定时互不共用唤醒：即使新期限早于另一相位的旧唤醒，
也按新的更早期限动作。

## 属性与端口

| 属性               | 默认   | 说明                                          |
| ------------------ | ------ | --------------------------------------------- |
| `f0KHz`            | 38 kHz | 带通中心频率（R6 设定），仅元数据，不参与行为 |
| `outputResistance` | 25 Ω   | OUT 开漏拉低时的等效串联电阻                  |
| `lowThreshold`     | 0.8 V  | IN 采样低电平上限                             |
| `highThreshold`    | 2.0 V  | IN 采样高电平下限                             |

| 端口        | 方向   | 类型    | 说明                                        |
| ----------- | ------ | ------- | ------------------------------------------- |
| `carrier`   | input  | boolean | 载波是否照射外接光电二极管                  |
| `receiving` | output | boolean | 已检出载波并把 OUT 拉低；只在状态变化时发布 |

启动时 `receiving` 先发布一次 `false`。

## 实现要点

- 启动过程 `process start` 同时是该通道的唯一消费者：先释放 OUT 并发布初值，再进入
  `loop { const level = await carrier.receive(); }`。
- 翻转只比较「与上一次接受的载波电平是否不同」，因此重复电平不会重新计时。
- 定时到点时不重复发布：只有在解调状态真正翻转时才写 `receiving`，所以「已检出时再次
  检出」和「未检出时释放」都不产生多余消息。

## 理想化

模拟器件的数字化行为模型：放大、f0 带通滤波、检波积分、脉冲整形与 inhibit/AGC 均不模拟；
载波检出简化为布尔阈值，照明是布尔而不是波形；不模拟传播延迟、驱动强度与电源电流。

## 测试

`test/cx20106a.test.ts`：99 µs 仍释放 / 100 µs 已拉低、150 µs 释放、检出中途翻转取消、
重复电平不重臂、已检出时重新检出保持状态、释放定时挂起时按更早的检出期限动作，以及
`receiving` 的发布历史。OUT 电平由板级 10 kΩ 上拉后经探针采样。
