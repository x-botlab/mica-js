# LM386 音频功率放大器

CT107D 板位号 **U14**：板上 LM386D 音频功放，输入接 N_SPK 网络，经 GAIN / BYPASS 网络驱动喇叭 SP1。本模型是理想数字跟随器——数字网络无法表示模拟波形，线性放大不建模。

## 元数据

| 项       | 值                                                      |
| -------- | ------------------------------------------------------- |
| 器件 id  | `lm386`                                                 |
| 文件     | `src/devices/lm386/{model.ddl,index.ts,device.json}`    |
| 位号前缀 | `U`                                                     |
| 引脚数   | 8                                                       |
| 数据手册 | [TI LM386](https://www.ti.com/lit/ds/symlink/lm386.pdf) |

## 引脚

| 引脚              | 方向/电气    | 说明                                              |
| ----------------- | ------------ | ------------------------------------------------- |
| `inp`             | 输入         | 同相输入，真实名称 INP（板上接 N_SPK / PWM 信号） |
| `inn`             | 输入         | 反相输入，真实名称 INN（板上通常接地）            |
| `out`             | 输出（推挽） | 逻辑电平输出，真实名称 OUT                        |
| `gain1` / `gain8` | 被动         | 增益设置脚，跨接电容时 ×200，仅声明               |
| `bypass`          | 被动         | 旁路电容脚，仅声明                                |
| `vcc` / `gnd`     | 电源         | 5 V 逻辑域                                        |

## 行为

伪差分数字跟随：

```
OUT = (INP 为高 且 INN 为低) ? 高 : 低
```

INN 接地（板上常规接法）时 OUT 跟随 INP；把 INP 与 INN 驱动到同一电平即可抑制输出。教学上对应「MCU PWM → 喇叭」路径：OUT 复现输入的开关波形。

输出以 `outputResistance`（默认 25 Ω）推挽到 `vcc` 或 `gnd`，装配负责把这两根电源引脚接到真实的 5 V / 0 V 网络。

## 属性与端口

| 属性   | 类型   | 默认 | 说明                                                 |
| ------ | ------ | ---- | ---------------------------------------------------- |
| `gain` | number | 20   | 只接受 20 或 200；数字模型中两档结果相同，仅作元数据 |

| 端口     | 方向 | 类型    | 说明                       |
| -------- | ---- | ------- | -------------------------- |
| `active` | 输出 | boolean | OUT 当前是否被驱动为高电平 |

`active` 只在 OUT 状态变化时发布，初始化时先发布一次当前值。

## 理想化

- 不建模电压增益：`gain` 属性不影响行为，20 与 200 都只产生逻辑电平。
- 不建模偏置、GAIN / BYPASS 引脚网络与任何模拟波形；这三个引脚只声明为被动引脚。
- 不模拟电源电流、输出驱动强度、失真与温漂。
- 未知电平按低处理（只有 `Logic.high` 当作 1）。

## 测试

`test/lm386.test.ts`：

- 元数据：8 根引脚、`gain` 默认 20、`active` 类型为 boolean。
- INN 接地时 OUT 跟随 INP，`active` 同步变化。
- INP 与 INN 同电平（含 INN 拉高）时输出被抑制。
- `gain: 200` 只改元数据，输出行为与默认值相同。
