# VS1838 一体化 38 kHz 红外接收头

CT107D 板位号 **U20**：一体化红外接收头，光电二极管、前置放大与解调都在封装内。OUT 接入
N_HALL/N_A2 网络（经跳线选择）。本模型是解调去抖行为模型。

## 元数据

| 项       | 值                                                                                  |
| -------- | ----------------------------------------------------------------------------------- |
| 器件 id  | `vs1838`                                                                            |
| 文件     | `model.ddl` / `index.ts` / `device.json`                                            |
| 位号前缀 | `U`                                                                                 |
| 引脚数   | 3                                                                                   |
| 数据手册 | [厂商 VS1838B PDF（Sivago）](https://www.sivago.com.cn/upload/pdf/2022/VS1838B.pdf) |

## 引脚

| 引脚 | DDL 名 | 方向/电气    | 说明                                       |
| ---- | ------ | ------------ | ------------------------------------------ |
| OUT  | `out`  | 输出（开漏） | 检出载波拉低，空闲释放；高电平来自板级上拉 |
| VCC  | `vcc`  | 电源         | 5 V 逻辑域                                 |
| GND  | `gnd`  | 地           | 参考地                                     |

照明没有外部引脚（光电二极管在封装内部），只经 `carrier` 输入通道注入。

## 行为

`carrier` 输入通道驱动的去抖状态机：

- `carrier=true`：50 µs 检出定时器到点后把 OUT 拉低，短于 50 µs 的毛刺不触发；
- `carrier=false`：200 µs 释放定时器到点后释放 OUT；
- 输入翻转先取消相反相位的挂起定时，重复电平不重臂。

检出与释放各有一个定时过程，期限是 `now() + 时延` 的绝对时刻；睡到期限后复查 `armed`
与解调状态。两个定时互不共用唤醒，因此释放定时还在挂起时出现的新载波仍按自己更早的
检出期限动作。

## 属性与端口

| 属性               | 默认  | 说明                                         |
| ------------------ | ----- | -------------------------------------------- |
| `outputResistance` | 25 Ω  | OUT 开漏拉低时的等效串联电阻                 |
| `lowThreshold`     | 0.8 V | 预留阈值属性；本器件没有采样引脚，行为不使用 |
| `highThreshold`    | 2.0 V | 预留阈值属性；本器件没有采样引脚，行为不使用 |

| 端口        | 方向   | 类型    | 说明                                        |
| ----------- | ------ | ------- | ------------------------------------------- |
| `carrier`   | input  | boolean | 38 kHz 载波是否照射接收头                   |
| `receiving` | output | boolean | 已检出载波并把 OUT 拉低；只在状态变化时发布 |

启动时 `receiving` 先发布一次 `false`。

## 实现要点

- 启动过程 `process start` 同时是该通道的唯一消费者：先释放 OUT 并发布初值，再进入
  `loop { const level = await carrier.receive(); }`。
- 翻转只比较「与上一次接受的载波电平是否不同」，因此 30 µs 之类的短毛刺只会在相反相位
  重新起算，永远不会把 OUT 拉低。
- 定时到点时不重复发布：只有解调状态真正翻转时才写 `receiving`。

## 理想化

不模拟 38 kHz 频率匹配、AGC（连续载波约 60 ms 后停止响应）与脉冲整形；照明是布尔值
而不是波形；不模拟传播延迟、驱动强度与电源电流。

## 测试

`test/vs1838.test.ts`：49 µs 仍释放 / 50 µs 已拉低、30 µs 毛刺不触发、200 µs 释放、
检出中途翻转取消后仍能正常检出、重复电平不重臂、释放定时挂起时按更早的检出期限动作，
以及 `receiving` 的发布历史。OUT 电平由板级 10 kΩ 上拉后经探针采样。
