# 3D 场景模式设计方案总结

## 设计目标

在现有 Mica 仿真器架构基础上，增加 3D 场景模式，支持物理维度的机器人仿真，特别是教育场景中的激光切割亚克力板建模。

---

## 核心设计理念

### 1. 架构原则

- **分层复用**：复用 `@mica-js/core`、`@mica-js/device`、`@mica-js/simulator`，新增 `@mica-js/scene-3d` 和 `@mica-js/scene-editor`
- **统一时钟**：物理仿真与电气仿真共享 `TimePs` 虚拟时间
- **确定性**：可复现的仿真结果，支持步进、暂停、回放
- **平行模式**：与 2D Widget 模式共存，共享 `.sch` 原理图

### 2. 物理引擎选型

**MuJoCo (WASM)**：

- 专为机器人关节系统设计
- 内置传感器支持（IMU、相机、力传感器等）
- 完全确定性
- 官方 JavaScript/WASM 绑定

### 3. 文档格式

`.scene3d` (JSON)：物理引擎无关，支持未来迁移到其他引擎。

---

## 实体系统

### 统一的模型实体

所有物理对象都是 `ModelEntity`，通过 `physics.bodyType` 区分：

- `static`：静态场景（墙壁、迷宫、地面）
- `dynamic`：动态物体（球、机器人零件）
- `kinematic`：运动学控制对象

### 几何类型支持

1. **基础形状**：盒子、球、圆柱、胶囊、平面
2. **标准 3D 模型**：STL、GLB、GLTF、OBJ
3. **亚克力板建模**：2D 轮廓 + 厚度挤出（核心特色）
4. **地形**：高度图

---

## 亚克力板建模系统（核心特性）

### 设计理念

模拟真实激光切割工艺，用户像设计实体零件一样在 2D 平面绘制轮廓，系统自动生成 3D 模型和物理属性。

### 轮廓定义

```typescript
type AcrylicContour =
  | { type: 'rect'; width: number; height: number }
  | { type: 'circle'; radius: number }
  | { type: 'polygon'; points: Vec2d[] }
  | { type: 'svg'; path: string } // 从 CAD 导入
  | { type: 'compound'; contours: AcrylicContour[] }; // 支持打孔
```

### 材质预设系统

**场景级预设库**：

- 内置预设：标准亚克力、PC板、木板、铝板、钢板等
- 每个预设包含：密度、摩擦、弹性、默认颜色、透明度
- 实体可引用预设并局部覆盖

**使用模式**：

```typescript
// 简单用法：使用预设
{ material: 'acrylic', thickness: 3, color: '#ff0000' }

// 覆盖密度：特殊材料
{ material: 'acrylic', thickness: 3, density: 1.5 }

// 纯局部配置
{ thickness: 3, density: 0.9, color: '#00ff00' }
```

### 典型应用

1. **机器人底板**：矩形 + 安装孔
2. **循迹赛道**：白色板 + 黑线纹理
3. **支架臂**：SVG 导入复杂轮廓
4. **半透明装饰板**：彩色亚克力 + 印刷图案

### 物理属性自动计算

- 面积计算（支持打孔）
- 质量 = 面积 × 厚度 × 密度
- 自动生成碰撞体（凸包或精确网格）
- 惯性张量计算

## 关节系统

### 关节类型

- `revolute`：旋转关节（轮子）
- `prismatic`：平移关节（伸缩臂）
- `spherical`：球形关节（三自由度）
- `fixed`：固定连接

### 电机控制

三种控制模式（通过话题接收指令）：

- **位置模式**：目标角度/位移
- **速度模式**：目标角速度/线速度
- **力矩模式**：直接施加力矩/推力

### 状态反馈

通过话题发布：

- 当前位置/角度
- 当前速度/角速度
- 约束力/力矩

---

## 装配体系统

### 层级结构

- 多个模型通过关节连接成树形结构
- 子实体在父实体局部坐标系中定义
- 支持整体操作（移动、旋转、复制）

### 预制机器人

- 两轮差速机器人
- 四轮麦克纳姆轮机器人
- 机械臂
- 可通过编辑器自定义装配

---

## 传感器系统

### 视觉类

- **摄像头**：RGB 图像 + 深度图（MuJoCo 渲染）
- **颜色传感器**：从地面纹理采样（循迹用）

### 测距类

- **距离传感器**：前方障碍物距离（超声波/红外）

### 运动类

- **IMU**：陀螺仪（角速度）+ 加速度计（MuJoCo 内置）
- **GPS**：全局位置（场景坐标 → 经纬度）

### 环境类

- **光照传感器**：环境光强度
- **声音传感器**：声音强度

### 接触类

- **触觉传感器**：接触力（MuJoCo 内置）
- **遮挡传感器**：光电门（检测物体通过）
- **磁力传感器**：磁场强度（干簧管）

### 传感器特性

- 固定更新频率（可配置）
- 挂载到模型上（随模型运动）
- 数据通过话题发布到原理图设备
- 支持噪声模拟（IMU、GPS 等）

---

## 编辑器功能

### 3D 场景编辑器

- Three.js 视口与相机控制（OrbitControls）
- 实体选择与 Transform Gizmo
- 预制件库（拖放创建）
- 属性面板（位置、旋转、物理属性、传感器配置）
- 实时物理预览

### 2D 轮廓编辑器（亚克力板专用）

**绘制工具**：

- 矩形、圆形、多边形、自由曲线
- 节点编辑（移动、添加、删除顶点）
- 布尔运算（合并、减去、相交）
- 倒角、圆角、阵列复制

**导入导出**：

- SVG 文件导入（Illustrator/Inkscape）
- DXF 文件导入（CAD 常用格式）
- 图片轮廓提取（自动描边）

**辅助功能**：

- 网格对齐、吸附
- 尺寸标注
- 实时质量预览
- 质心显示

**3D 预览**：

- 实时挤出预览
- 厚度调整滑块
- 材质预设选择
- 颜色/透明度调整
- 纹理上传

---

## 时间同步与确定性

### 虚拟时间统一

- 物理仿真与电气仿真共享 `TimePs`（皮秒）
- 物理步长可配置（默认 16.67ms / 60Hz）
- 支持子步细分（保证稳定性）

### 确定性保证

- 相同输入 → 相同输出
- 支持录制回放
- 支持单步调试

---

## 技术栈

- **物理引擎**：MuJoCo (WASM)
- **渲染引擎**：Three.js
- **几何处理**：Earcut（三角化）、QuickHull（凸包）
- **2D 轮廓**：SVG path、多边形
- **文档格式**：JSON (`.scene3d`)
- **类型系统**：TypeScript

## 实现路线图

### Phase 1：基础架构（2-3 周）

- 创建 `@mica-js/scene-3d` 包
- 定义 `.scene3d` 文档格式
- 集成 MuJoCo WASM
- 实现 ModelEntity 和 PhysicsConfig
- 实现 Scene3DRuntime 与时间同步

### Phase 2：亚克力板建模（1-2 周）

- 2D 轮廓数据结构（SVG、多边形等）
- 几何挤出算法（Earcut 三角化）
- 材质预设系统
- 物理属性自动计算
- Three.js 渲染 + 碰撞体生成

### Phase 3：关节与装配体（1-2 周）

- 关节系统（revolute、prismatic）
- 话题集成（接收指令、发布状态）
- 装配体系统
- 预制机器人模型

### Phase 4：传感器系统（2-3 周）

- 传感器基类
- 基础传感器（距离、颜色、IMU、GPS）
- 摄像头传感器（离屏渲染）
- 其他传感器（光照、声音等）

### Phase 5：编辑器（2-3 周）

- `@mica-js/scene-editor` 包
- Three.js 视口与相机控制
- 2D 轮廓编辑器
- SVG/DXF 导入
- Gizmo 与实体操作
- 预制件库、属性面板

### Phase 6：集成与优化（1-2 周）

- Playground 示例场景
- 性能优化（物理步长、LOD）
- 文档与测试
- 与 2D Widget 共存测试

**总工期**：9-13 周

## 补充说明

### 坐标系统

- **世界坐标系**：右手系（X 右，Y 上，Z 前），单位米
- **MuJoCo 适配**：Z 轴向上 → Y 轴向上转换
- **角度约定**：文档存弧度，UI 显示度

### 单位约定

- **长度**：文档米 (m)，编辑器 UI 毫米 (mm)
- **质量**：文档千克 (kg)，密度克/立方厘米 (g/cm³)
- **时间**：虚拟时间皮秒 (ps)，物理步长毫秒 (ms)
- **角速度**：弧度/秒 (rad/s)

### 碰撞事件

- 提供 `onCollision` 订阅接口
- 支持触摸传感器、遮挡传感器
- 碰撞冲量、接触点、法向量

### 调试可视化

- 碰撞体线框
- 关节轴向和锚点
- 传感器范围（锥形、视锥）
- 质心、惯性主轴、受力箭头

### 错误处理

- 场景验证（轮廓、关节、传感器）
- 运行时诊断（性能统计）
- 错误恢复策略（回退、占位符）

### 性能优化

- 物理休眠（MuJoCo 自动管理）
- 渲染 LOD
- 传感器优化（降低分辨率、合批）

## 总结

该方案通过新增两个包（`scene-3d` 和 `scene-editor`），在保持现有架构优势的同时，为 Mica 仿真器带来完整的 3D 物理仿真能力。亚克力板建模系统和材质预设库使其特别适合教育场景，用户可以像设计真实激光切割零件一样构建虚拟机器人。
