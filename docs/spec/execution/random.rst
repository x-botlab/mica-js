.. _spec-random:

================================================
实例随机序列
================================================

``random()`` 在执行位置推进本实例的确定性随机流。普通函数、过程与 JIT 路径共享该实例的流，跨实例互不消耗；分支选择、调用顺序及调用次数决定取值顺序。语言效果限制见 :doc:`/language/builtins`。

状态与输出
------------------------------------------------

首版使用 xoshiro128**。有效初始状态为按顺序排列的四个无符号 32 位整数 ``[s0, s1, s2, s3]``，每项范围为 0 至 4_294_967_295，四项不能全部为零。非法状态在建立随机流前拒绝，不隐式截断、补值或替换全零种子。

每次调用取得一个无符号 32 位输出 r，并返回 ``r / 4_294_967_296``。该结果可以由 binary64 精确表示，范围为 ``[0, 1)``，分辨率为 ``2^-32``。一次调用恰好推进一次状态，不额外合并两个输出，也不跳过零输出。

状态转换
------------------------------------------------

下列步骤固定算法，而非公开可变状态接口。所有中间状态按 32 位无符号整数处理，乘法截取低 32 位，左移丢弃高位；``rotl32(x, k)`` 将 32 位 x 循环左移 k 位，``xor`` 表示按位异或。

.. code-block:: text

   r  = low32(rotl32(low32(s1 * 5), 7) * 9)
   t  = low32(s1 << 9)
   s2 = s2 xor s0
   s3 = s3 xor s1
   s1 = s1 xor s2
   s0 = s0 xor s3
   s2 = s2 xor t
   s3 = rotl32(s3, 11)
   return r / 4294967296

赋值严格按上述顺序使用已更新的状态，输出 r 使用转换前的 s1。结果和四字新状态共同构成一次成功调用的效果。运行中其他实例的执行、编译块重建或宿主调用耗时均不改变该流。

生命周期与宿主配置
------------------------------------------------

实例在创建时确定有效初始状态。普通状态赋值、代码装载和 JIT 缓存失效不重设随机流；DDL 不提供修改种子的操作。销毁旧板并以等价配置创建新板，相同调用序列重现相同结果；原板的执行位置或随机状态不转移到新板。

宿主通过 :doc:`/javascript/host` 的 ``options.seed`` 配置板级主种子。它 MUST 是 0 至 4_294_967_295 的整数，省略为 0，不接受截断或隐式转换。实例的 ``randomState`` 如果给出，MUST 恰有四个符合本章要求的 uint32，且不能全零；它直接成为该实例初始状态，不再与主种子混合。无效显式状态拒绝，不使用下述派生兜底代替。

未覆盖状态的实例，仅按板 seed 和原始实例 ID 派生。重排实例、加入无关实例、改变类型、属性或网络均不改变已有 ID 的派生结果。执行层接收最终四字状态，不自行读取宿主时间或宿主随机源；不同 ID 的派生不承诺数学上互不重叠的随机流。

固定派生算法
------------------------------------------------

先把 seed 编码为四个小端字节，再追加实例 ID 的 UTF-8 字节；不插入分隔符。UTF-8 编码将未配对 UTF-16 代理项替换为 U+FFFD，不做 Unicode 规范化。下列所有中间值取 uint32；``imul`` 为乘法截取低 32 位，``>>>`` 为无符号右移，``xor`` 为按位异或：

.. code-block:: text

   h = 2166136261
   for byte in seed_le32_then_id_utf8:
       h = low32(imul(h xor byte, 16777619))
   for i in 0, 1, 2, 3:
       h = low32(h + 0x9e3779b9)
       z = low32(imul(h xor (h >>> 16), 0x85ebca6b))
       z = low32(imul(z xor (z >>> 13), 0xc2b2ae35))
       s[i] = low32(z xor (z >>> 16))
   if s[0] == 0 and s[1] == 0 and s[2] == 0 and s[3] == 0:
       s[0] = 1

第一段是 FNV-1a，第二段使用连续累加状态与固定整数混合展开。仅派生结果允许上述全零修正；它不改变对显式 randomState 的严格校验。原始 ID 比较仍是精确字符串比较，因此编码相同的不同字符串可能派生相同状态，不影响装配 ID 唯一性规则。
