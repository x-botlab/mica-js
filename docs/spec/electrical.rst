.. _spec-electrical:

================================================
电气意图与网络采样
================================================

板级装配提供理想参考电位，器件通过引脚间的电阻支路影响网络。运行时在调度边界求解并统一发布采样快照。本章是参考电位、支路数值、阈值和求解失败的行为来源；语言与 IR 使用同一合同。

引脚与理想参考
------------------------------------------------

``pin`` 是实例拥有的双向电气端点。装配中的直接连接建立等电位网络，未列入网络的引脚仍有自己的未连接网络。

板级网络可以具有显式固定电位。地网的电位为 0 V，理想电源网的电位为创建时给定的有限 ``number``，允许零和负值，单位为伏。全部电位参考同一地坐标，整个板级运行期间保持不变；重新创建板时从捕获的新装配描述建立约束。理想参考由板内建提供，不需要电源器件或 JavaScript 工厂，负载不使参考电位发生压降。

器件只声明普通引脚并贡献电阻支路；供电、地及多电源域通过这些引脚的显式装配连接表达。器件不能直接引用板级电源或地，不能生成理想电压源。网络或引脚的名称不产生连接或参考约束。

按装配网络和当前有效电阻支路形成连通分量。分量含任意固定电位网络时具有对地参考，不要求另接地网；完全不含固定电位网络时为浮空。例如，仅经上拉电阻连到固定 3.3 V 电源网的输入具有参考；经电阻连到一个未驱动且名为 ``VCC`` 的网仍可能浮空。

多个不同电位的参考网可以经电阻相连，各自保持固定值。同一网络上的固定电位约束必须一致；矛盾约束在任何工厂调用前拒绝。多个相同电位约束可以共存，0 与 -0 视为相同。

接收阈值
------------------------------------------------

引脚可同时给出 ``low``、``high``，或同时省略。显式阈值使用创建期表达式，结果 MUST 为有限数且满足 ``low < high``，允许负值；仅提供一个阈值、相等或倒置阈值均在创建期且工厂调用前拒绝。

.. code-block:: text

   pin contact(low: 0.8, high: 2.0);
   pin supply;
   pin reference;

阈值省略时不选用隐含电压制式，该引脚仍提供电压与状态，``level`` 恒为 ``Logic.unknown``。显式配置时按已发布电压比较：电压小于或等于 low 为 ``Logic.low``，大于或等于 high 为 ``Logic.high``，两者之间为 ``Logic.unknown``。比较不使用历史电平形成迟滞，也不以数值容差扩大阈值范围。

意图与支路
------------------------------------------------

``pin.intent`` 表达引脚贡献的电阻支路。``resistor(to: target, resistance: r)`` 返回 ``intent``；目标只接受当前实例的直接 pin 引用或 pin 形参。构造时尚无支路起点，赋给 pin 后，以该 pin 为起点、目标 pin 为另一端。经辅助函数传递仍保留实例归属。

``[first, second]`` 合并支路，``[]`` 构造空意图。这些构造允许在 ``pure fn`` 中使用；只有 ``pin.intent <- value`` 才更新网络贡献，该写入不是纯效果。``intent`` 可保存为局部、作为函数形参或返回值，也可以可空，但不提供内容相等比较。

电阻使用 ``number``，单位为欧姆，MUST 为有限值且属于闭区间 ``[0.001, 1_000_000_000]``，即 1 mΩ 至 1 GΩ。实际执行 ``resistor`` 构造操作时检查，超界不截断、不转换为短路或开路；非法构造即使没有赋给引脚也失败。未执行分支不产生运行期构造错误，可静态确定的错误允许提前报告。

运行期非法构造属于框架错误，使整板 ``faulted``；尚未执行的 intent 赋值不发生，之前的资源效果保留。合法数值不替代实例归属与目标类别检查。

每个引脚只有一份当前意图。赋值 MUST 完整替换原有意图；``[]`` 仅移除该引脚贡献的支路。每条贡献都是独立电阻；两端引脚各贡献一条电阻时，两条都参与求解，不按端点自动去重。目标与起点经装配处于同网时，合法支路的净节点贡献为零，可以跳过数值计算，参数构造检查仍执行。

.. code-block:: text

   contact.intent <- [
     resistor(to: supply, resistance: 25),
     resistor(to: reference, resistance: 10000)
   ];
   contact.intent <- [resistor(to: reference, resistance: 10000)];

第二次赋值仅留下到 reference 的支路。同片段的边界求解只使用最终意图。模型通过到供电或地引脚的电阻表达高低电平，通过移除支路表达释放；理想等电位连接由装配表达。

同实例共享与提交边界
------------------------------------------------

同实例的过程和动态执行入口默认可以更新同一引脚。普通函数同步执行，通过调用它的入口参与操作。资源共享的通用规则见 :doc:`/execution/sharing`。

同步片段内其他入口不能插入执行；同片段先后对同一引脚赋值，后写替换前写。同一时刻不同片段的执行顺序遵循 :doc:`/execution/scheduling`。

在同步片段结束的调度边界，运行时使用各引脚最终生效的意图求解网络，并发布新的采样。片段中被后写替换的中间意图 MUST NOT 作为额外支路参与该次求解，也不产生独立采样。

片段内读取 ``pin.sample``，得到上一次求解发布的快照。在片段中更新意图不会立即改变这一读取结果。是否形成新片段取决于操作是否实际挂起，见 :doc:`/execution/index`。

``sample`` 在求解边界发布；``derived`` 始终反映依赖当前已生效的值，不能在发布前观察新采样，也不能在发布后保留陈旧缓存。边界求解、变化检测与反应入队顺序见 :doc:`/execution/scheduling`。

采样字段
------------------------------------------------

``pin.sample`` 是只读的 ``sample`` 值快照，按字段比较相等。采样由引脚读取取得，不能手工构造；可保存为局部值、作为函数形参或返回值，也可使用可空形式。保存的采样在后续求解后仍保留原内容。

.. list-table:: 采样结构
   :header-rows: 1
   :widths: 22 78

   * - 字段
     - 含义
   * - ``voltage``
     - 确定的对地电压，类型为可空 ``number``；浮空时为 ``none``。
   * - ``level``
     - 按读取引脚的接收阈值解释的 ``Logic.low``、``Logic.high`` 或 ``Logic.unknown``。
   * - ``status``
     - 状态全集为 ``SampleStatus.valid`` 与 ``SampleStatus.floating``。

``Logic`` 的完整成员为 ``low``、``high``、``unknown``。逻辑解释使用本章接收阈值规则；所有电压均为相对板级统一地坐标的值。

``SampleStatus.valid`` 表示电压已确定，不表示逻辑结果一定为高或低。多个电阻支路产生位于阈值之间的电压时，采样可以同时具有确定的 ``voltage``、``valid`` 状态与 ``unknown`` 电平；不同供电方向的支路共同求解，不产生额外的冲突状态。

浮空采样的 ``voltage`` 为 ``none``、``level`` 为 ``Logic.unknown``、``status`` 为 ``SampleStatus.floating``。浮空是可观察的网络状态，不能解释为逻辑低。

同一网络的电压由共同求解得到；各引脚使用自己的阈值解释逻辑电平。一个引脚读取采样时，读取的是网络结果，也包括其他引脚支路的影响。

通知或其他模型事件只能报告事件发生。若调用方需要某次求解的历史电压，应保存当次采样值，而不是以后重新读取当前 ``pin.sample``。

线性求解与数值接纳
------------------------------------------------

运行时按节点电压法处理当前电阻网络。固定电位是已知边界条件；其余节点按基尔霍夫电流定律列方程。对未知节点 i，相邻支路 e 的另一端记为 j(e)，电阻为 r(e)，电导为 g(e)：

.. math::

   g_e = 1 / r_e, \qquad
   \sum_{e\ni i} g_e (V_i - V_{j(e)}) = 0.

同网支路先排除零净贡献。每条剩余电阻对两个端点的贡献相反；固定电位代入后，对含参考的分量求解未知电压。只有正电阻，故数学上的未知节点电导矩阵为对称正定；首版采用直接线性求解，可利用稀疏 Cholesky 或 LDL 分解。具体算法和库由实现选择，不增加非线性迭代机制。

全为固定电位的分量直接取得已知值；固定节点之间的电阻不改变这些电位。求解接纳只检查未知节点电压；sample 未公开的支路电流不参与接纳条件。完全浮空的分量直接生成浮空快照，不求未公开的相对电压，也不添加泄漏电阻或悄悄接地。

浮空分类基于合法支路的原始拓扑。极弱连接不能被当成开路；含参考的分量若在数值计算中丢失必要约束、分解失败或无法可靠表示必要系数，应报告求解失败，而非浮空。

候选解必须经过适当缩放、有限性与分解有效性检查，并通过逐未知节点的归一化残差校验。令 d(i) 为该节点所有非同网支路的电导和，w 为各条支路的归一化权重；V(j(e)) 包括相邻未知节点候选值和固定电位：

.. math::

   d_i = \sum_{e\ni i} g_e, \qquad w_{ie} = g_e / d_i,
   \qquad \sum_{e\ni i} w_{ie} = 1,

.. math::

   \left|V_i - \sum_{e\ni i} w_{ie} V_{j(e)}\right|
   \le 10^{-12}\left(|V_i| + \sum_{e\ni i} w_{ie}|V_{j(e)}|\right).

右侧为零时，左侧必须为零。检查使用原节点方程，而非消元后的方程；实现可以使用等价缩放避免中间溢出。参考电位本身精确作为边界值采用，不受此残差容差调整。

``1e-12`` 是统一固定的相对残差容差，由运行时内部使用，不作为器件、引脚或首版宿主调参接口。它验收方程平衡，不是逻辑电平死区，也不承诺病态网络的真实电压前向误差上界。首版不另设统一小主元或条件数拒绝门槛；必要计算的非有限值、数值分解失效及残差不合格均按求解失败处理。

成功采样发布有限计算值，仅将 -0 统一为 +0。运行时不额外量化电压，也不以“与旧值很接近”保留旧采样；逻辑解释直接比较已发布值。采样变化继续采用 :doc:`/execution/scheduling` 的精确稳定值比较。

相同运行环境、相同装配及支路顺序、相同输入序列必须得到相同发布结果；求解次序不能依赖偶然的异步完成顺序。允许缓存未变化网络的结果。不要求拆分、重排支路等数学等价改写或不同求解器实现得到逐位相同的电压。

初始求解与失败发布
------------------------------------------------

每块新板首次推进先求解，再建立观察基线并启动模型，见 :doc:`/execution/scheduling`。模型首次可读的是初始求解成功的快照，不发布“尚未求解”的浮空占位值。销毁并重新创建板后重新执行此顺序，不使用旧板采样作为初值。

一次边界的采样发布是全板统一的：全部必要分量通过求解与接纳后，才发布本次所有新快照，再执行派生更新与变化检测。任一分量真正求解失败时，整板 MUST 进入 ``faulted``，本次边界所有新采样均不发布，保留上次完整快照。已发生的时间、state、memory、intent 等效果不回滚。

求解失败不新增可继续运行的错误采样状态；后续反应、等待恢复与 sync 遵守 :doc:`/errors` 的停机规则。首次求解失败时，没有本代次的成功采样，启动过程不执行，本次推进失败。

诊断至少区分非法电气参数、矛盾固定电位装配与数值求解失败。参数错误定位所属实例、引脚声明或构造操作，装配错误定位网络，求解错误定位相关网络或分量；运行期诊断包含当前仿真时间与失败原因。公开事件字段及分类码由 :doc:`/javascript/host` 维护。

行为示例
------------------------------------------------

装配将 supply 连到固定 3.3 V 电源网，reference 连到 0 V 地网，contact 保持独立网络。器件通过普通引脚表达电阻，而不是直接引用参考电位：

.. code-block:: text

   device ContactExample {
     pin contact(low: 0.8, high: 2.0);
     pin supply;
     pin reference;

     process start {
       contact.intent <- [];
       await ticks(1);
       const previous = contact.sample;

       contact.intent <- [resistor(to: supply, resistance: 25)];
       const before_boundary = contact.sample;
       await ticks(1);
       const current = contact.sample;

       contact.intent <- [
         resistor(to: supply, resistance: 10000),
         resistor(to: reference, resistance: 10000)
       ];
       await ticks(1);
       const divided = contact.sample;
     }
   }

``before_boundary`` 仍是释放后的浮空快照，下一边界后 ``current`` 为约 3.3 V 的有效采样；``previous`` 保留原内容。最后的等阻分压结果约为 1.65 V，状态为 valid、电平为 unknown。数值接纳不把真实阈值附近的计算结果吸附到阈值。

一致性检查
------------------------------------------------

:doc:`/conformance` 的电气场景覆盖多参考供电、浮空、阈值、支路校验、数值接纳和全板原子发布。数学预期用来组织测试，不能把文档构建视为求解器或运行时已实现的证据。
