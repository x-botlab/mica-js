# 虚拟时间模型

> **状态**：提案（OPEN） · **来源**：[#23](https://github.com/x-botlab/mica-js/issues/23) · **同步**：2026-10-25
> **实现**：[`packages/core/src/scheduler/time.ts`](../../packages/core/src/scheduler/time.ts)
> **相关**：[器件 IR 核心](./device-ir.md) · [IR 引脚 I/O](./ir-pin-io.md) · [电气模型](./electrical-model.md)

仿真的全部时间值统一使用整数皮秒。本文规定时间值的单位、表示、范围、换算、运算、校验与序列化。

## 表示

- 基础时间单位固定为皮秒（ps），分辨率 1 ps。
- 时间值使用 JavaScript `number` 表示，取值非负整数。
- TypeScript 使用品牌类型 `TimePs`（基于 `number`）在编译期区分时间值与普通数值，运行时仍是数值。
- 时间戳表示相对仿真起点的位置，起点为 0；时长表示间隔。时间戳与时长共用 `TimePs`。

## 取值范围

| 项目   | 值                                                                 |
| ------ | ------------------------------------------------------------------ |
| 最小值 | `0` ps                                                             |
| 最大值 | `7_200_000_000_000_000` ps（2 小时）                               |
| 边界   | 两端均包含                                                         |
| 精确性 | 上限小于 `Number.MAX_SAFE_INTEGER`，范围内每个整数皮秒都可精确表示 |

时间戳、时长、单位换算结果与时间运算结果都必须落在该范围内。

## 单位换算

| 时间单位 | 皮秒数            |
| -------- | ----------------- |
| 1 ps     | 1                 |
| 1 ns     | 1,000             |
| 1 µs     | 1,000,000         |
| 1 ms     | 1,000,000,000     |
| 1 s      | 1,000,000,000,000 |

换算接受对应单位的非负整数值。

```ts
toTimePs(1, 'ns'); // 1_000
toTimePs(7_200, 's'); // MAX_TIME_PS
```

## 运算

| 运算                | 结果         | 约束                             |
| ------------------- | ------------ | -------------------------------- |
| 时间戳 `+` 时长     | 新时间戳     | 结果在范围内                     |
| 较晚 `-` 较早时间戳 | 时长         | 结果为非负；相同时间戳之差为 `0` |
| 比较                | 整数大小关系 | 输入满足类型与范围要求           |

## 校验与错误

校验顺序：数值类型 → 有限性 → 整数性 → 取值范围。TypeScript、JavaScript 与外部数据输入走同一套规则。

| 情形                          | 错误         |
| ----------------------------- | ------------ |
| 非 `number`、非有限值或非整数 | `TypeError`  |
| 负值或超过 2 小时上限         | `RangeError` |
| 换算或运算结果越界            | `RangeError` |
| 时间戳求差得到负值            | `RangeError` |

错误信息包含输入名称、非法值与对应约束；结果越界时说明涉及的运算与允许范围。

## 序列化

时间值在 JSON 中保存为表示整数皮秒的数值，合法范围内可精确往返。读取后的数值按同一套类型、整数性与范围规则校验后才作为时间值使用。
