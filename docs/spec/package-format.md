定义通用包的元数据、包内文件路径与基础安装规则。包直接携带实际文件；后续内容规范在此基础上增加各自的包字段与内容规则。

## 包结构

包根包含 `package.json`；文档与其他内容文件按需携带：

```text
<包根>
├── package.json
├── README.md
└── LICENSE
```

`package.json` 是基础元数据文件；`README.md` 与 `LICENSE` 示意可选文档位置。内容目录由对应内容规范确定。

## 基础元数据

```json
{
  "name": "example-package",
  "version": "1.0.0",
  "description": "示例包",
  "license": "MIT"
}
```

| 字段          | 类型   | 约束                     |
| ------------- | ------ | ------------------------ |
| `name`        | string | 必填，非空，包的稳定标识 |
| `version`     | string | 必填，非空，包的发行版本 |
| `description` | string | 可选，展示说明           |
| `license`     | string | 可选，许可证说明         |

同名包可以具有多个发行版本，同一发行版本发布后保持固定。包名的字符集、大小写规则、版本语法与版本选择规则由宿主采用的包名与版本规则判定。

## 包内路径

- 包内文件使用相对包根的路径定位；内容对象的身份由对应内容索引表达。
- 合法内容路径解析到包根内的普通文件；清单中的内容路径唯一，包内资源可由多个内容对象共享引用；路径校验错误返回明确诊断。
- 安装与解压遵循文件数量、单文件大小及总大小额度，扩展声明的额度以宿主上限为界。
- 路径分隔、规范化、大小写碰撞与路径唯一性按宿主的路径规则处理。

## 基础安装与校验

1. 读取 `package.json`，要求内容为单个完整 JSON 对象，且对象键唯一。
2. 校验基础元数据及包内文件边界、文件种类与额度。
3. 按宿主采用的内容规范校验内容，通过清单中的显式声明注册对象。
4. 安装消费已准备完成的包文件，执行文件落地与静态校验。

官方、第三方、预装与离线导入采用同一组基础规则。安装、实现运行与权限授予分别具有各自的生命周期。组合后的完整字段集合由实际采用的内容规范决定；宿主根据已具备的内容能力报告安装与注册结果。
