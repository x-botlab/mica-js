================================================
表达式
================================================

表达式在当前语义位置取得值。除短路和条件选择外，子表达式从左到右求值；成员和索引先计算接收值，再计算索引，记录字段和字节、意图列表按源码顺序计算。赋值不是表达式。

读取与调用
------------------------------------------------

名称可引用属性、常量、局部或资源的值读取。state 返回即时值，sample 返回最近发布快照，derived 返回反映已生效依赖的值。保存到局部后，后续使用仍是保存值；资源更新通过新的读取观察，见 :doc:`/ir/resources`。

普通函数允许出现在表达式中，其同步副作用按求值顺序发生；无返回调用只能作为语句。调用使用全部位置实参或全部命名实参，两种形式 MUST NOT 混用。全部形参必须匹配且恰好提供一次；实参按源码顺序计算，不因形参声明顺序重排：

.. code-block:: text

   combine(first(), second());
   combine(right: second(), left: first());

第一行先 first 后 second；第二行先 second 后 first。方法调用只开放 :doc:`builtins` 定义的端点操作，不开放任意宿主方法。类型名不是转换函数，函数也不能作为值保存或动态调用。

运算表与优先级
------------------------------------------------

下表从高到低排列。除幂与条件选择右结合外，其余二元运算左结合；一元运算向右结合。

.. list-table::
   :header-rows: 1
   :widths: 30 40 30

   * - 运算
     - 输入
     - 结果
   * - ``.``、``[]``、调用
     - 由成员、索引或签名决定。
     - 对应值或调用结果。
   * - ``**``
     - number、number。
     - number。
   * - 一元 ``+``、``-``、``!``、``~``
     - 前二者及 ~ 为 number；! 为 bool。
     - number 或 bool。
   * - ``*``、``/``、``%``
     - number、number。
     - number。
   * - ``+``、``-``
     - number、number；+ 另接受 string、string。
     - number 或 string。
   * - ``<<``、``>>``、``>>>``
     - number、number。
     - number。
   * - ``<``、``<=``、``>``、``>=``
     - number、number。
     - bool。
   * - ``==``、``!=``
     - 可相等比较的同类型值，或可空值与 none。
     - bool。
   * - ``&``
     - number、number。
     - number。
   * - ``^``
     - number、number。
     - number。
   * - ``|``
     - number、number。
     - number。
   * - ``&&``
     - bool、bool；左为 false 时不求右侧。
     - bool。
   * - ``||``
     - bool、bool；左为 true 时不求右侧。
     - bool。
   * - ``condition ? yes : no``
     - bool 条件，具有共同值类型的两分支。
     - 只计算被选中分支。

幂与一元采用 JavaScript 的括号要求：``-2 ** 2`` 拒绝，必须写 ``-(2 ** 2)`` 或 ``(-2) ** 2``。``2 ** -2`` 合法。上述运算的类型检查不进行隐式字符串、数值或布尔转换。

数值结果
------------------------------------------------

普通数值运算采用对应 JavaScript binary64 运算；``%`` 是余数而非总为非负的模。例如 ``-5 % 3`` 为 -2。``**`` 与 pow 一致。除零、负数开平方等可产生 Infinity 或 NaN，不因普通算术本身报告模型故障。操作入口的值检查仍可拒绝这些结果。

位运算采用 JavaScript ToInt32 / ToUint32：有限小数向零截断，再按 32 位回绕；NaN 和无穷大转为零。移位量转换后取低 5 位。``>>>`` 返回无符号 32 位数值，其他位运算返回有符号 32 位数值，静态类型均为 number。此转换不适用于地址、时长或存储写值的合法性检查。

相等与条件
------------------------------------------------

数值相等使用严格数值相等，不做类型转换：NaN 不等于任何值，包括自身；正负零相等；含 NaN 的四种大小比较均为 false。bool 与 number 间比较静态拒绝，不另提供 ``===`` 或 ``!==``。

string、bool、枚举、记录、bytes、sample 与同类资源引用的相等规则见 :doc:`types`。可空相等先比较 none：两边均 none 相等，仅一边为 none 不等，其余按非空类型比较。none 与 none 可直接比较。intent 只能通过可空性检查与 none 比较，不能比较两份意图内容。

有序比较仅接受 number。逻辑运算仅接受 bool。三元表达式不产生可赋值位置或资源引用；其共同值类型可以是同一类型、T 与 T?，或 T 与 none 形成 T?，不生成其他联合类型。

纯计算与等待
------------------------------------------------

derived 与 pure fn 沿调用图接受纯效果检查；创建期表达式另施加更窄的读取限制，见 :doc:`functions`、:doc:`declarations`。random 是有状态操作，now 是时间依赖读取，两者都不能作为纯计算。

await 不是通用表达式。它只出现在独立语句、局部声明或赋值的完整右侧；不能嵌入实参、算术、条件或返回表达式，见 :doc:`statements`。redirect 则使用独立控制语法 ``redirect(target, delay: duration)``，不属于普通函数混用实参的许可。
