================================================
文件、词法与名称
================================================

文件与定义
------------------------------------------------

每个 ``.ddl`` 文件恰好包含一个 ``device`` 定义。枚举、记录、器件级常量、资源、函数与过程均在该定义内声明。文件自包含；首版语言没有模块、导入导出或跨文件名称解析。

源文件采用 UTF-8，可以包含文件开头的 BOM；接受 LF 与 CRLF。换行编码不改变模型含义。诊断保留文件与源码范围，行列从 1 开始，列按 UTF-16 代码单元计数，以便映射编辑器位置。诊断对象的公开接口由 :doc:`/ir/builder` 所属接口设计维护。

标识符与注释
------------------------------------------------

标识符大小写敏感，匹配 ``[A-Za-z_][A-Za-z0-9_]*``。``//`` 注释持续到行尾；``/* ... */`` 是不可嵌套的块注释。空白与注释分隔词法单元，不能插入一个标识符、数字或多字符运算符的内部。注释与字符串可以包含中文。

简单语句以分号结束，不执行自动分号插入。语句块使用花括号；``else if`` 可以直接连写。参数、实参、枚举成员和记录字段列表允许末尾分隔符。

结构关键字包括 ``device``、``default``、``const``、``let``、``enum``、``record``、``state``、``derived``、``pin``、``memory``、``fn``、``pure``、``process``、``on``、``if``、``else``、``match``、``while``、``loop``、``break``、``continue``、``return``、``await``、``assert`` 与 ``redirect``；``true``、``false``、``none`` 为值记号。它们不能作为用户声明名称。

``input``、``output`` 与 ``public`` 是声明上下文中的修饰符，``channel`` 与 ``notification`` 在端点声明中识别。其他名称位置仍接受这些拼写，例如 ``fn output()`` 和 ``pin out;``。``start`` 专用于启动过程名称。

数值字面量
------------------------------------------------

支持十进制整数、小数、科学计数法以及 ``0x``、``0b``、``0o`` 前缀的整数字面量。小数点两侧都要有数字，例如 ``0.5`` 与 ``1.0``；``.5`` 与 ``1.`` 不是合法字面量。指数部分可以有正负号。前缀大小写均可使用。

数字之间允许单个下划线，例如 ``1_000``、``0xff_ff``、``1.25e+3``。下划线不能位于前缀后、结尾、小数点或指数标记旁，也不能连续出现。前导零不产生旧式八进制解释。负号是独立的一元运算。

字面量转换为最接近的 binary64 值，等距时取偶数尾数。有限但不安全的整数仍是合法 ``number``；操作需要安全整数时另行检查。转换溢出为无穷大的字面量在编译时拒绝，使用 ``Infinity`` 显式表达无穷大。普通算术产生非有限值的规则见 :doc:`expressions`。

字符串
------------------------------------------------

字符串使用双引号，支持 ``\"``、``\\``、``\n``、``\r``、``\t``、``\uXXXX`` 和 ``\u{...}`` 转义。``\uXXXX`` 表示一个 UTF-16 代码单元；码点形式的数值范围为 0 至 0x10ffff。非法转义与未转义换行在编译时拒绝。

字符串可以直接包含 Unicode 文本，值按 UTF-16 代码单元序列表达。首版不提供单引号字符串、原始字符串或模板插值。长度与索引见 :doc:`types`。

名称解析与作用域
------------------------------------------------

device 的属性、器件级 ``const``、资源、derived、函数、过程和自定义类型共享一个名称空间，名称必须唯一。枚举成员和记录字段各自拥有内部名称空间，其内部名称必须唯一。

类型、函数和器件级创建期依赖允许前向引用。函数调用图与创建期依赖图分别检查无环；derived 依赖图也必须无环，见 :doc:`functions` 与 :doc:`declarations`。

参数、局部绑定不能遮蔽当前可见的器件成员、参数或外层局部。兄弟块中互不包含的局部可以复用名称。局部名称在自身初始化完成后可用，初始化不能读取自身。``const`` 与 ``let`` 都必须有初值。

内置类型、枚举、常量与函数名称由 :doc:`types` 和 :doc:`builtins` 给出，不能被用户声明遮蔽。命名实参的标签和成员访问按对应声明匹配；例如内置存储函数接受 ``memory: data`` 标签，该标签不声明一个名为 ``memory`` 的局部。

函数与过程仅在 device 体内声明。块内使用局部声明、语句和控制结构；不嵌套定义 device、函数或过程。
