.. _spec-ir-resources:

================================================
资源与引用
================================================

资源引用标识具体实例中的对象。它与普通值不同：把一次读取的结果保存到局部变量，不会将局部变量变成对资源的持续订阅。

资源行为
------------------------------------------------

.. list-table::
   :header-rows: 1
   :widths: 18 40 42

   * - 对象
     - 读取
     - 更新与生效
   * - 属性
     - 创建时校验和补全的静态配置。
     - 创建时确定，在实例生命周期内保持不变。
   * - state
     - 当前值。
     - 写入后，后续读取立即可见。
   * - memory
     - 显式操作取得的字节值或快照。
     - 按存储操作的范围和可见性规则更新。
   * - derived
     - 当前已生效依赖的计算结果。
     - 由依赖维护，只读。
   * - pin
     - 最近发布的只读 sample。
     - intent 赋值完整替换该 pin 的当前意图，边界求解后发布采样。
   * - channel
     - receive 取得的一条消息值。
     - send 捕获值并按通道规则尝试入队。
   * - notification
     - 触发或批次中的通知记录。
     - 无业务负载的通知按交付批次合并。

属性在表中用于对照静态配置与运行资源，不因此获得可变资源操作。memory 细节见 :doc:`/memory`；pin 见 :doc:`/electrical`；channel 与 notification 见 :doc:`/channels`。

可见性与派生依赖
------------------------------------------------

state 写入立即生效，derived 读取依赖当前已生效的值。例如派生值为 ``count + 1``，同片段写入 count 后再次读取派生值，必须取得新结果。实现采用立即维护或按需重算都必须产生这一结果。

变化通知在同步片段结束时按源的最终结果判定，不改变 state 与 derived 的即时可见性。片段内往返写入可以不产生变化通知，见 :doc:`/execution/scheduling`。

sample 同样受发布边界约束。修改 intent 后，片段内读取的 sample 仍是最近一次求解的结果。派生计算不能替代电气求解，也不能提前观察尚未发布的采样。

派生依赖在静态检查时形成无环图。动态代码引用 derived 时遵守相同读取规则，不要求模型显式刷新。声明与表达式限制见 :doc:`/language/declarations`。

实例共享
------------------------------------------------

同实例的过程、JIT 入口及被调用函数可以访问其上下文允许使用的同一资源。普通函数的读写归调用入口，派生计算是只读投影。

跨入口的顺序以同步片段和调度阶段为准，见 :doc:`/execution/scheduling` 与 :doc:`/execution/sharing`。IR 中的引用身份不能据单入口示例固化为单一 owner；直接状态赋值按执行顺序后写覆盖。channel 的单消费者要求继续按 :doc:`/channels` 检查，共享 state 与 memory 不扩大为竞争接收同一队列的许可。

实例私有引用不扩展为跨实例任意读写。其他实例通过连接、消息及规范规定的接口交互，装配关系见 :doc:`/assembly`。

JavaScript 访问
------------------------------------------------

配对 JavaScript 的普通资源接口与它生成的 IR 分别检查权限。能够为 DDL 资源构造操作，不代表生成方可以在宿主执行期间直接读写同一资源。

公开存储、消息快照和代码装载分别遵守 :doc:`/memory`、:doc:`/javascript/interfaces` 及 :doc:`/jit/code-memory`。装载只允许本实例工厂初始化或两次完整推进之间的 idle，包括 idle 中的话题回调；工厂须先绑定、后装载。sync 及其嵌套回调中禁止装载；资源须仍有未释放代码绑定，public 不扩大装载权限，阶段判定见 :doc:`/javascript/host`。

公开存储的 ``BorrowedBytes`` 句柄在本板未销毁时可跨推进复用，在允许读取的阶段观察当前内容。下一次推进、销毁或同存储成功非空装载结束内容稳定期；结束稳定期不使句柄失效，保存旧内容须事先复制。translate 的专用代码视图仅在本次同步回调期间有效。属性与消息的 ``ReadonlyBytes`` 均为可跨推进、装载和销毁留存的独立快照。

销毁后的资源、引用与旧 context 的失效规则由 :doc:`/javascript/lifecycle` 规定。恢复须创建独立新板，旧 context 的错误上报只产生过期诊断，不改变新板状态；已经交付的消息快照不因旧资源释放而改写。
