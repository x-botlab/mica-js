.. _spec-memory:

================================================
字节存储
================================================

``memory`` 是实例独立、固定长度的可变字节区。DDL 与生成的共享 IR 使用显式操作读写字节；配对 JavaScript 通过公开借用视图读取，并通过受控接口装载已绑定的代码存储。

本章定义已确认的存储合同，尚不表示运行时已经实现。JavaScript SDK 的精确签名见 :download:`host.d.ts <contracts/host.d.ts>`，阶段与生命周期见 :doc:`/javascript/host`。值类型、声明和内置操作见 :doc:`/language/types`、:doc:`/language/declarations` 和 :doc:`/language/builtins`；代码绑定与版本规则见 :doc:`/jit/code-memory`。

声明与初始内容
------------------------------------------------

.. code-block:: text

   memory storage[256];
   public memory visible[16];
   memory empty[0];

长度的单位为字节，类型统一为 ``number``。长度 MUST 在创建期求值为非负安全整数，允许为零。表达式可以引用 ``props``、器件常量及满足创建期限制的纯函数，实例生命周期内属性与存储长度保持不变。

运行时为每个实例独立分配存储，初始字节全部为零。两个实例声明同名 ``memory``，仍拥有各自的内容。

``state`` 保存普通可变值，类型包括 ``number``、``bool``、``string``、具名枚举、扁平记录、``bytes`` 及其可空形式。``memory`` 则以字节偏移访问，每个字节的可读数值范围为 0 至 255。

``memory`` 与 ``pin`` 可以作为函数资源形参，实参直接使用资源名或同类形参；资源不能存入局部变量、作为返回值或成为可空值。

重新初始化通过销毁整板后创建新板完成。新板独立分配全零存储，新工厂按代码装载合同初始化；旧 context 和借用句柄失效，不能影响新板，生命周期见 :doc:`/javascript/host`。

整数读写
------------------------------------------------

.. list-table:: 内置读写操作
   :header-rows: 1
   :widths: 27 33 12 28

   * - 读取
     - 写入
     - 字节数
     - 读取结果范围
   * - ``load8``
     - ``store8``
     - 1
     - 0 至 255
   * - ``load16le`` / ``load16be``
     - ``store16le`` / ``store16be``
     - 2
     - 0 至 65535
   * - ``load32le`` / ``load32be``
     - ``store32le`` / ``store32be``
     - 4
     - 0 至 4294967295

读取形态为 ``loadX(memory, offset)``，写入形态为 ``storeX(memory, offset, value)``。读取结果统一为无符号 ``number``；其他数值解释由模型函数完成。

``le`` 表示小端，低偏移保存低位字节；``be`` 表示大端，低偏移保存高位字节。端序由操作名称显式指定，``memory`` 本身没有端序属性。

写入值 MUST 是安全整数。操作取相应宽度的低位作为写入内容，负值采用相同转换。例如：

.. code-block:: text

   store8(storage, 0, 256);
   let first = load8(storage, 0);
   store16le(storage, 1, 4660);
   let second = load16be(storage, 1);
   store32be(storage, 4, -1);
   let third = load32be(storage, 4);

``first`` 为 0；偏移 1、2 的字节分别为 52、18，``second`` 为 13330；``third`` 为 4294967295。

小数、``NaN``、正负无穷大和非安全整数是非法写入值。存储操作的低位转换不改变普通 ``number`` 的 IEEE 754 binary64 数值规则；普通位运算采用 JavaScript 的 32 位规则。字节字面量 ``bytes[expr, ...]`` 则逐项要求 0 至 255 的整数，不采用存储写入的低位转换。

偏移、范围与非对齐
------------------------------------------------

偏移以字节计，MUST 是非负安全整数。对于长度 ``N``、偏移 ``offset``、访问宽度 ``width``，完整访问范围须满足：

.. code-block:: text

   offset <= N && width <= N - offset

运行时按原值校验偏移，不对偏移隐式取整或回绕。多字节访问允许任意满足范围要求的字节偏移；例如，``load32le(storage, 1)`` 访问偏移 1 至 4。

长度为 16 的存储允许 ``load8(storage, 15)``，但偏移 16 不足以完成任何整数读写。零长度存储可以声明，对其执行宽度为 1、2 或 4 的读写均因范围不足失败。

模型需要额外地址规则时，在底层访问前显式检查，并自行定义对应的状态变化或控制路径。底层存储操作统一按本章范围规则校验。

单次操作与共享
------------------------------------------------

每次读取或写入同步完成，自身不推进仿真时间。运行时 MUST 在写入前校验全部参数及完整范围；失败时，该次操作不修改任何目标字节。

一次多字节写入期间，其他仿真入口不能插入并观察部分结果。先前已经完成的状态或字节更新继续保留；单次操作的完整性不扩展为整个函数、同步片段或推进批次的回滚保证。

同实例的过程、同步边界反应体和动态执行入口默认共享同一份 ``memory``。同步片段中的后续读取立即看到先前写入；实际挂起后，其他入口可以按调度顺序更新存储。同步边界反应的全部 pure 捕获在任何反应体写入前完成；捕获的字节值保持不可变快照，较后反应体的普通存储读取则可见较早反应体的成功写入。memory 本身不是直接变化源，可通过读取它的 derived 形成静态值源，也可作为等待谓词依赖。通用共享与时间规则见 :doc:`/execution/sharing` 和 :doc:`/execution/scheduling`。

存储访问的仿真耗时由模型显式表达。模型也可以在字节存储之上定义自己的写入条件与状态变化。

DDL 中非法参数或越界访问报告执行错误并终止本次推进；统一故障分类、``faulted`` 与恢复规则见 :doc:`/errors`。错误发生前已经完成的更新不会回滚。

代码存储与受控装载
------------------------------------------------

代码存储仍是普通 ``memory``；通过执行入口绑定后，额外参与整块代码版本跟踪与缓存失效。写入后的指令边界和缓存处理遵守 :doc:`/jit/code-memory`。

``ctx.loadBytes(memory, bytes, offset)`` 的精确签名由 :download:`host.d.ts <contracts/host.d.ts>` 的 ``JitHost`` 维护：资源名为 ``string``，源数据为 ``Uint8Array``，返回 ``void``，仅省略 ``offset`` 时采用默认值 0。显式 ``undefined`` 或 ``null`` 按原值校验，不能代替省略。

``memory`` 是当前实例的存储名称。该存储 MUST 至少有一个尚未释放的 ``attachJit`` 注册绑定，工厂中也须先注册、后装载。入口 ``stop`` 保留绑定和装载权限；释放最后一个相关注册撤销装载权限。``public`` 只授予借用读取，不产生写入或装载权限。

允许装载的窗口为本实例工厂初始化，以及两次完整推进之间的 ``idle`` 阶段，包括在 ``idle`` 中调用的话题回调。``sync`` 及其嵌套话题回调、模型执行、``translate`` 和清理阶段 MUST NOT 装载。``faulted`` 或已销毁的板拒绝装载，阶段判定见 :doc:`/javascript/host`。

装载同步复制源视图 ``byteOffset`` 与 ``byteLength`` 选中的范围；成功返回后修改源视图或父数组不影响目标内容。非空成功装载更新代码版本，并结束同一存储先前内容的稳定期，即使写入字节与原值相同。装载不改变执行位置，也不重新启动已停止入口。

复制前 MUST 先依次检查 context 或对象有效性、当前调用阶段与同板重入、操作所需板状态，再校验资源名称、绑定权限、源类型、偏移和完整范围。守卫按所属板隔离，独立板的回调不会使本板自动处于重入状态。失败按 :doc:`/javascript/host` 的分类抛出异常，不部分写入，也不改变代码版本或内容稳定期。偏移与范围沿用本章的非负安全整数规则，复制长度由所选源视图的字节数确定。

空数据仍须通过全部校验，允许 ``offset == memory.length``；校验成功后不修改字节、代码版本或内容稳定期。``offset > memory.length`` 即使数据为空也非法，非空数据从末尾位置写入则越界。

异常逸出运行时调用的工厂或回调时，按 :doc:`/errors` 与 :doc:`/javascript/host` 处理；单次写入完整性不撤销此前已经完成的状态变化。

公开借用与消息快照
------------------------------------------------

``public memory`` 通过 ``ctx.memory.name`` 暴露 ``BorrowedBytes``。它与 ``ReadonlyBytes`` 具有相同的读取能力，但分别表示活的借用句柄和自有只读快照；精确成员由 :download:`host.d.ts <contracts/host.d.ts>` 集中定义。

两者均提供只读 ``length``、``byteLength``、数值索引及 ``[Symbol.iterator](): IterableIterator<number>``，索引读取结果为 ``number | undefined``，有效字节为 0 至 255，越界索引为 ``undefined``。``slice(start?, end?): Uint8Array`` 按 JavaScript 下标规则处理负下标和截断，返回调用方拥有的可修改副本。接口不暴露 ``buffer`` 或写入能力。

``BorrowedBytes`` 句柄在所属板未销毁时可以跨推进反复使用，在允许读取的阶段观察当前内容。内容稳定期持续到下一次推进、所属板销毁或对同一存储成功执行非空 ``loadBytes``，以先发生者为准；结束稳定期不等于句柄失效。

读取阶段为本实例工厂初始化、``idle`` 和 ``sync``；``faulted`` 且尚未销毁时可读取保留现场。非法阶段读取或使用已失效句柄 MUST 抛出 ``SimulationError``，包括长度、索引、迭代和复制操作。翻译回调 MUST 使用本次专用代码视图，不能读取捕获的 ``ctx.memory``；专用代码视图仅在本次回调期间有效，见 :doc:`/javascript/host`。

需要保留历史内容时，调用方 MUST 在稳定期结束前取得自有副本。原始存储归仿真器持有，跨 RPC 传输先复制，再复用现有 transfer hooks 传递副本。

通知时间可能早于批次结束；``sync`` 中借用读取反映批末最终内容，不是通知时刻的历史内容。需要历史数据时，模型应在对应时刻使用 ``copyBytes`` 保存快照，其范围与发送规则见 :doc:`channels`。

字节属性和已交付字节消息统一使用 ``ReadonlyBytes``；后续推进、装载或销毁不改变已取得快照和 ``slice`` 自有副本。销毁使旧 context 和借用句柄失效，新板工厂独立取得新句柄；旧装载操作拒绝执行，不影响新板。

一致性检查
------------------------------------------------

以下为实现验收预期，非已执行结果；通用方法见 :doc:`/conformance`。

* 同名存储在两个实例中互不影响；销毁后创建新板，其存储独立清零并由新工厂初始化。
* 长度 0 合法；负长度、小数长度及非安全整数长度在声明校验时失败。
* 非对齐的合法范围可以访问；负数、小数、无穷大及非安全整数偏移失败。
* ``store32le`` 在长度 16、偏移 14 时失败，偏移 14、15 的字节均保持原值。
* ``store8`` 写入 256 得到 0，写入 -1 得到 255；大小端解释符合示例，32 位读取仍返回 ``number``。
* 非法写入值不修改目标字节；第二次操作失败不撤销第一次成功写入，单次访问自身不增加仿真时间。
* 同实例不同入口按稳定顺序共享存储；单次多字节操作的中间状态不可被其他入口观察。
* ``loadBytes`` 复制源数据；名称、权限、时机或范围错误均不部分写入，末尾零长度装载仍执行全部校验。
* 工厂先注册后装载；停止保留装载权，释放最后绑定后即使空装载也失败。
* ``idle`` 话题回调可以装载；``sync`` 及其嵌套话题回调、翻译和清理中装载失败。
* 空装载校验通过后不改变版本或稳定期；非空成功装载即使内容相同也结束该存储的稳定期。
* 同一借用句柄跨推进读取当前内容；非法阶段及销毁后读取抛出 ``SimulationError``。
* ``ReadonlyBytes`` 与自有副本跨推进和销毁保留内容；借用索引越界为 ``undefined``，``slice`` 使用 JavaScript 下标规则。
