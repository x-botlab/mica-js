# 器件电源域声明与运行时供电状态

> **状态**：提案（OPEN） · **来源**：[#13](https://github.com/x-botlab/mica-js/issues/13) · **同步**：2026-10-25
> **实现**：[`packages/core/src/power/`](../../packages/core/src/power/)
> **相关**：[器件定义](./device-definition.md) · [引脚声明](./device-pins.md) · [电气模型](./electrical-model.md) · [内部可控连接](./device-topology.md) · [IR 核心](./device-ir.md)

器件用 `powerDomains` 描述供电引脚、接地参考、上下电阈值与域依赖，用信号引脚的 `powerDomain` 关联所属域。内核依据连接网络的供电电压计算域状态，并把它作用于实体信号引脚的输出、采样与边沿门控；器件 IR 通过公共生命周期入口接收状态变化，自行维护复位、状态保留、通信状态机与恢复。

## 声明结构

### 顶层字段

| 字段路径                   | 类型   | 必填 | 默认值 | 说明                               |
| -------------------------- | ------ | ---- | ------ | ---------------------------------- |
| `powerDomains`             | object | 可选 | `{}`   | 域 ID 到域描述的映射               |
| `powerDomains.<domain-id>` | object | 必填 | —      | 单个域的供电、接地、阈值与依赖声明 |

域 ID 在器件内稳定、唯一、长度至少为 1、大小写敏感（如 `core`、`io`、`motor`）。每个实例独立维护自己的域状态。

### 电源域字段

| 字段路径          | 类型            | 必填 | 默认值 | 说明与约束                                                 |
| ----------------- | --------------- | ---- | ------ | ---------------------------------------------------------- |
| `supply`          | string          | 必填 | —      | 引用当前器件中 `kind: power` 的实体引脚                    |
| `ground`          | string          | 必填 | —      | 引用 `kind: gnd` 的实体引脚，检查其与全局 GND 网络的连通性 |
| `voltage`         | object          | 必填 | —      | 上下电阈值对象                                             |
| `voltage.turnOn`  | number          | 必填 | —      | 上电阈值，单位 V，有限数值且大于 `turnOff`                 |
| `voltage.turnOff` | number          | 必填 | —      | 下电阈值，单位 V，非负有限数值                             |
| `dependsOn`       | array of string | 可选 | `[]`   | 前置域 ID 集合，元素唯一，集合语义                         |

`supply`、`ground` 按大小写精确匹配。多个域可以共享供电引脚与接地引脚，各自采用自己的阈值与依赖。

全局 GND 节点及其连通网络固定为 0 V 电势：`ground` 引脚接入该网络时 `groundReady` 为 `true`。接地判断采用网络拓扑身份——由全局 GND 节点建立参考，`kind: gnd` 表达引脚类别，普通信号的 0 V 输出仍保留信号网络身份；孤立接地引脚在接入全局 GND 后获得接地就绪状态。

接地就绪且供电电势确定时：

$$V_{domain} = V_{supply},\qquad V_{GND} = 0$$

接地条件失效时，域设置 `groundReady: false`、`voltage: null`、`state: off`；接地恢复后按上电阈值与依赖重新计算。`dependsOn` 中的每个域都引用同一器件描述内的电源域，依赖图支持拓扑排序，每条依赖边连接两个相异的域。依赖只表达供电就绪条件；实际电流路径、稳压关系与电压转换由电气连接与器件模型表达。

### 引脚关联

| 字段路径                    | 类型   | 必填         | 默认语义                     | 说明                   |
| --------------------------- | ------ | ------------ | ---------------------------- | ---------------------- |
| `pins.<pin-id>.powerDomain` | string | 信号引脚可选 | 引脚沿用器件自身生命周期管理 | 引用当前器件已声明的域 |

适用于 `kind: signal` 的引脚；每个信号引脚关联一个域，域的多重供电前置条件通过 `dependsOn` 表达。关联粒度为实体引脚：同一引脚的数字输出、模拟输出、数字采样与输入观察共同采用该域的门控。`power`、`gnd` 引脚作为供电网络观测与连接点由电气模型持续解析。

### 数字输入电平门限

| 字段路径               | 类型   | 必填                 | 默认语义                       | 说明                     |
| ---------------------- | ------ | -------------------- | ------------------------------ | ------------------------ |
| `pins.<pin-id>.levels` | object | 信号引脚可选         | 沿用器件电气模型的输入判定规则 | 基于所属域电压的门限对象 |
| `levels.low`           | number | 提供 `levels` 时必填 | —                              | 低电平电压上限比例       |
| `levels.high`          | number | 提供 `levels` 时必填 | —                              | 高电平电压下限比例       |

使用 `levels` 的引脚同时提供 `powerDomain`。两个比例为有限数值且 $0 \le low < high \le 1$（示例采用 `0.3` 与 `0.7`）。同一实体引脚的各数字输入功能共享该规则。

域接地就绪时以全局 0 V 为参考，$V_D = V_{supply}$、$V_{in} = V_{pin}$。域为 `on` 且输入电势确定时：

| 条件                                        | 数字输入结果                               |
| ------------------------------------------- | ------------------------------------------ |
| $V_{in} \le low \times V_D$                 | `0`                                        |
| $V_{in} \ge high \times V_D$                | `1`                                        |
| $low \times V_D < V_{in} < high \times V_D$ | 门限区间：返回上次逻辑值，保留内部区间诊断 |

仿真器在以下两种实现中选择其一，并在仿真能力信息中声明所选模式；同一次仿真统一采用选定模式。

| 模式     | 确定电压的判定                                  | `low` 的作用             |
| -------- | ----------------------------------------------- | ------------------------ |
| 三态模式 | 按上表分类，门限区间保持上次逻辑                | 定义低电平上限           |
| 二态模式 | $V_{in} \ge high \times V_D$ 为 `1`，否则为 `0` | 保留声明，供三态实现使用 |

每个引脚独立维护数字逻辑记忆，新实例初值 `0`。确定低、高电平分别更新记忆为 `0`、`1`；三态模式的门限区间保持记忆。解释在信号电压、域电压、接地或门控变化的相关解析阶段完成，主动采样与观察使用共同结果。浮空与门控的回退取值保持记忆，只有确定的低、高电平解释会更新它；域为 `off` 时先执行供电门控。

`voltage.turnOn/turnOff` 以 V 为单位控制域状态，`levels.low/high` 是比例控制输入判定。参与判定的域先满足接地就绪，发送端网络电压与接收端比例门限统一采用全局 0 V 参考；开漏释放状态的电压由上拉与网络驱动解析，兼容性判定使用实际网络电压。

## 声明示例

```json
{
  "pins": {
    "GND": { "kind": "gnd" },
    "VDD": { "kind": "power" },
    "VDDIO": { "kind": "power" },
    "DB0": { "kind": "signal", "powerDomain": "io" },
    "DB1": { "kind": "signal", "powerDomain": "io" },
    "CORE_READY": { "kind": "signal", "powerDomain": "core" },
    "DIN": { "kind": "signal", "powerDomain": "io", "levels": { "low": 0.3, "high": 0.7 } }
  },
  "powerDomains": {
    "core": { "supply": "VDD", "ground": "GND", "voltage": { "turnOn": 2.7, "turnOff": 2.5 } },
    "io": {
      "supply": "VDDIO",
      "ground": "GND",
      "voltage": { "turnOn": 1.65, "turnOff": 1.5 },
      "dependsOn": ["core"]
    }
  }
}
```

IO 域为 `on`、供电 3 V 时，`DIN` 的低门限为 0.9 V、高门限为 2.1 V：

| `DIN` 相对域接地的电压 | 三态模式                       | 二态模式 |
| ---------------------- | ------------------------------ | -------- |
| 0.9 V                  | `0`                            | `0`      |
| 1.5 V                  | 保持上次逻辑（初始记忆为 `0`） | `0`      |
| 2.1 V                  | `1`                            | `1`      |

数字输入按模式判定；模拟观察仍使用实际电压。

## 运行时状态

| 状态项              | 类型               | 初始值         | 含义                                                 |
| ------------------- | ------------------ | -------------- | ---------------------------------------------------- |
| `state`             | `off` \| `on`      | `off`          | 当前逻辑供电状态                                     |
| `voltage`           | 有限数值 \| `null` | `null`         | 接地就绪时的供电电压，单位 V，参考全局 0 V           |
| `groundReady`       | boolean            | 按接地拓扑计算 | `ground` 引脚接入全局 GND 所在网络时为 `true`        |
| `dependenciesReady` | boolean            | 按依赖状态计算 | 全部直接依赖域处于 `on` 时为 `true`，空依赖为 `true` |

接地就绪且供电引脚具有确定有限电势时取得域电压；否则电压为 `null`、状态为 `off`。内核计算域状态，器件 IR 通过公共生命周期入口消费状态变化与完整域快照。降低到 IR 时，域状态、接地就绪、依赖就绪与电压有效性拆分为标量，电压采用 `f64`；待确定分支的电压槽填正零占位。

### 初始化

1. 创建全部域，初始状态统一 `off`。
2. 检查接地连通性，解析供电电压，按依赖拓扑顺序求初始稳定状态。
3. 器件通过公共生命周期入口取得完整电源状态快照，完成供电相关的内部初始化、配置准备与功能选择；上电延时用普通定时事件表达，期间引脚维持初始化门控状态。
4. 内核依据初始化结果开放就绪引脚的采样与驱动。

初始电压位于迟滞区间时域保持 `off`；达到上电阈值且全部依赖就绪时进入 `on`。

### 迟滞与依赖

| 优先级 | 条件                                                            | 下一状态   |
| ------ | --------------------------------------------------------------- | ---------- |
| 1      | `groundReady` 为 `false`、域电压为 `null`，或任一依赖域为 `off` | `off`      |
| 2      | 域电压 $\le$ `turnOff`                                          | `off`      |
| 3      | 域电压 $\ge$ `turnOn` 且全部依赖为 `on`                         | `on`       |
| 4      | 域电压位于 `turnOff` 与 `turnOn` 之间且全部依赖为 `on`          | 保持原状态 |

边界包含等号：达到 `turnOn` 上电，达到 `turnOff` 下电。依赖失去供电时当前域进入 `off`；依赖恢复后按当前电压与 `off` 状态重算——达到 `turnOn` 恢复为 `on`，处于迟滞区间则保持 `off`。域可以沿依赖链间接依赖，状态传播沿同一拓扑顺序完成。

### 同一仿真时刻的处理顺序

电源域的状态计算与门控效果必须在后续相关采样或触发捕获前可见，对应的生命周期入口在当前入口返回后、下一普通入口前由公共控制阶段执行。同一批拓扑与供电更新形成一致的接地连通状态与电压快照，按以下顺序应用：

1. 读取接地连通状态与供电电压快照，计算 `groundReady` 与域电压，按拓扑顺序求得全部域的新状态。
2. 对进入 `off` 的域先关闭引脚门控，释放对应输出与内部偏置，暂停相关输入观察捕获与边沿检测。
3. 通过公共生命周期入口向器件提供同一批状态变化与完整快照；下电通知按依赖方优先，上电通知按前置域优先。
4. 器件 IR 处理内部状态，并通过已声明的引脚配置与输出操作提交更新；通信状态与定时事件由器件自行管理。
5. 内核完成校验后开放已确认就绪的引脚，继续完成相关网络解析，并在控制阶段完成后调度下一普通入口。

同级域按稳定域 ID 排序，同一批次先下电后上电，跨实例按稳定实例身份排序。单次传播以完整域快照为准，依赖图计算完成后统一应用门控；信号释放引起的电气变化进入后续解析阶段。

每条通知携带实例、域 ID、仿真时间、原状态、新状态、域电压、`groundReady` 与 `dependenciesReady`；下电通知同时携带结构化原因集合（接地失效、供电电势待确定、达到下电阈值、依赖域关闭等）。

## 引脚门控与器件行为

### 输出门控

域为 `off` 时，内核释放该引脚的全部输出驱动（数字推挽、数字开漏拉低、模拟输出），并按供电合同释放内部偏置贡献；引脚配置与偏置选择继续保存。连接网络继续依据其他有效驱动、上下拉与电气模型解析电平。

域为 `on` 时引脚进入供电就绪状态，实际驱动由供电状态、器件激活条件、引脚配置与输出意图共同确定。器件 IR 提交输出意图及模式、使能、偏置等配置；恢复供电后内核以器件确认的配置与输出快照重新应用就绪条件。

### 输入与边沿门控

域为 `off` 时网络电势继续解析，器件侧新观察捕获与边沿检测暂停，输入逻辑记忆保存。门控下的采样返回值由 [IR 引脚 I/O](./ir-pin-io.md) 定义：数字为 `0`，模拟为正零。已捕获载荷与待执行事件不属于该就绪状态的写集合。

必需域或供电引脚引用缺失、目标不存在时，在链接期报告模型异常。已声明域在运行时供电电势暂待确定时，沿用 `voltage: null`、`state: off` 与就绪门控规则，暂停对应输入的新捕获；配置、意图与逻辑记忆的保存／复位由既有生命周期合同决定，其他就绪读取方继续工作。域恢复就绪时提供当前域电压、实际输入结果与就绪变化作为恢复处理的共同快照。

### 器件就绪与跨域行为

内核按实体引脚的域关联应用门控；器件 IR 读取域状态与引脚采样结果，结合内部状态计算业务就绪条件。跨域功能的供电组合、内部功能选择与通信使能由器件模型表达。

固定引脚组可以包含不同域的成员，每个成员分别采用对应引脚的门控结果：域关闭只影响所属成员，其余供电就绪成员继续工作；器件 IR 可以依据完整域状态管理业务整体执行条件。

### 通信状态与定时事件

UART、SPI、I²C、并口等通信行为由器件 IR 的状态机表达。域状态变化经公共生命周期入口到达器件，器件按自身通信合同处理部分接收数据、待发送数据、通信中止、状态保留与恢复。定时事件由器件依据事件合同管理，结合域状态决定取消、继续或重新安排；已完成交付、已提交副作用与已发生的边沿保持既有结果，器件可以依据供电变化生成 `power-domain-off` 等业务结果。供电恢复后，器件依据当前域状态、内部状态与已确认的引脚配置启动后续通信。

## 配置与内部状态恢复

域进入 `on` 表示供电条件就绪；器件完成相应初始化并确认引脚配置与输出后，内核开放对应的输入观察与输出驱动。器件实现显式选择各域变化对应的策略：

- 寄存器、存储与通信内部状态的保持或初始化。
- 运行时配置采用器件定义的保留值、复位值或初始化值。
- 数字输出值、模拟输出、PWM 状态与待发送数据的恢复方式。
- 内部功能选择、引脚配置、通信使能与业务就绪条件。

器件初始化与恢复采用器件模型定义的配置初值，以及显式配置指令的校验、提交与生效规则。供电恢复过程中的初始配置在开放对应引脚前完成；运行期间引脚配置按声明的生效边界提交，通信内部配置按器件 IR 定义的执行顺序更新。

## 校验

静态校验：

1. `powerDomains` 与各域条目为对象，域 ID 长度至少为 1 且唯一。
2. `supply` 引用已声明的 `power` 引脚，`ground` 引用已声明的 `gnd` 引脚。
3. `turnOn`、`turnOff` 为有限数值，满足 `turnOn > turnOff >= 0`。
4. `dependsOn` 为字符串数组，各项引用同一器件已声明的域且唯一。
5. 依赖图支持拓扑排序，每条依赖边的前置域与当前域各自独立。
6. `powerDomain` 所在引脚 `kind` 为 `signal`，引用的域已声明。
7. 引脚与域引用按大小写精确匹配。
8. `levels` 所在引脚为 `signal` 且提供有效 `powerDomain`，`low`、`high` 为满足 `0 <= low < high <= 1` 的有限数值。

运行时校验：域电压与状态必须与当前网络解析结果一致，`groundReady` 依据 `ground` 引脚与显式全局 GND 节点的连通性计算，域状态按接地就绪、当前电压、既有状态与依赖状态计算，数字输入按选定模式与当前域电压判定，同一批传播完成后统一执行引脚门控，输出与偏置释放、捕获暂停、门控采样与生命周期入口都具有确定的仿真时间与处理顺序，恢复后的引脚配置与输出经校验后进入执行状态。

## 行为示例

`GND` 已接入全局 GND 网络时：

| 步骤      | 核心域 | IO 域  | `core` | `io`  | 解释                              |
| --------- | ------ | ------ | ------ | ----- | --------------------------------- |
| 初始化    | 2.6 V  | 1.7 V  | `off`  | `off` | 核心处于迟滞区间，IO 等待前置域   |
| 核心上电  | 2.7 V  | 1.7 V  | `on`   | `on`  | 两域均达阈值，依赖满足            |
| IO 降压   | 2.7 V  | 1.6 V  | `on`   | `on`  | IO 处于迟滞区间，保持供电         |
| IO 下电   | 2.7 V  | 1.5 V  | `on`   | `off` | 达到下电阈值，释放 DB0、DB1 输出  |
| IO 回升   | 2.7 V  | 1.6 V  | `on`   | `off` | 迟滞区间保持下电                  |
| IO 恢复   | 2.7 V  | 1.65 V | `on`   | `on`  | 达到上电阈值，进入恢复流程        |
| 核心下电  | 2.5 V  | 1.7 V  | `off`  | `off` | 达到下电阈值，依赖关闭传播至 IO   |
| 核心恢复  | 2.7 V  | 1.6 V  | `on`   | `off` | 核心恢复，IO 等待自身达到上电阈值 |
| IO 再恢复 | 2.7 V  | 1.65 V | `on`   | `on`  | 两域重新就绪                      |

`GND` 断开全局 GND 网络时，共用该接地引脚的 `core`、`io` 均设置 `groundReady: false`、`voltage: null` 并进入 `off`；重新接入后按当前供电电压与上电阈值重新判定。
